## 2. 四个核心问题与可证伪结果

### Q1：弛豫、热化学与构象采样是否改变选择？

在同一背景、方法和可比 cohort 下，比较垂直电子能、绝热电子能、单构象自由能和同态系综自由能。分别报告数值位移、pair gap、选集变化及采样证据。若某一步同时改变方法、环境或基组，应明确为混合变化，不能单因归因。

### Q2：Li 条件配位是否改变氧化选择？

比较自由分子与 1:1 Li 条件态的氧化自由能，分析条件位移的候选间差异。每个状态独立允许弛豫与 motif 切换，并检查物种和电子身份。该问题针对指定物种条件，不直接预测真实电解液的平均 population。

### Q3：哪些变化超过独立敏感性、可以可靠解析？

依据独立方法审计、数值重算和已报告采样覆盖，区分同向稳定、稳健翻转与未解析关系。大部分关系未解析时，给出可能进入 Top-k 的候选集合与证据缺口，保留这种科学结果。

### Q4：恢复计算目标下的选择需要多少信息和成本？

比较廉价代理、直接学习、方法差值或条件位移学习，以及四种主动查询策略。以可追溯标签和成本为基础，分别报告全池选集恢复与未查询候选预测；模型没有优于随机时，报告本池内无节省证据。

项目允许下列结论：廉价模型已足够；只有数值 offset；存在稳健选择变化；状态身份改变导致连续回归失效；现有表示不能学习条件位移；当前证据不足以解析细排序。任何一种都必须附适用域、数据依据与限制。

## 3. 三轴研究框架与声明边界

| 研究轴 | 层级或对象 | 比较时回答的问题 |
| --- | --- | --- |
| 代理量与电子结构 | P0 廉价标量、P1 气相电子能/自由能、P2 固定介质电子能/自由能 | 同一目标定义下，增加电子结构或热化学信息如何改变选择？ |
| 环境与条件物种 | free、固定连续介质、li_1to1、少量 explicit_R | 条件变化和物种变化如何改变响应与身份？ |
| 外部参考 | gas anchors、solution anchors、环境趋势 | 计算目标在什么可比条件下受到实验或更高层证据支持？ |

共同背景采用 SMD 乙腈。候选均被解释为置于该共同 embedding 中的小分子、共溶剂或添加剂；即使候选本身为 EC、DMC 或 AN，也不等于它各自纯液体或实际盐配方。

输出不延伸为完整电化学稳定窗口、SEI/CEI 优劣、传输/黏度、真实浓度下 speciation、界面动力学或最佳配方。多性质展示采用分别报告或有明确目标的 Pareto 分析，不临时合成加权“最佳电解液分数”。Li 结合强度与条件位移本身不默认“越大越好”。

## 4. 目标量、方向与层级契约

原始总能量以 Eh 保存，分子间排序差值以 eV 为主，另可给 kJ/mol。所有量登记 `quantity_kind`、环境、几何、热化学、系综、方向和身份准入规则。

| 量 | 定义 | 排序用途 |
| --- | --- | --- |
| P0_ox | −ε_HOMO，明确方法与环境 | 廉价氧化标量参照，maximize |
| Eox_vertical | E(M+;r_M)−E(M;r_M) | 共用几何的垂直氧化电子能，maximize |
| Eox_adiabatic | E(M+;r_M+)−E(M;r_M) | 两态独立弛豫电子能，maximize |
| Gox_single | G_single(M+)−G_single(M) | 单极小自由能差，maximize |
| Gox_free_ensemble | G_ens(M+)−G_ens(M) | 首轮自由分子主目标，maximize |
| Gox_Li_ensemble | G_ens([LiM]2+)−G_ens([LiM]+) | Li 条件氧化主目标，maximize |
| coordination_shift | Gox_Li_ensemble−Gox_free_ensemble | 有符号条件响应，默认只分析、不直接优化 |
| Sred | G(reduced)−G(parent) | 合格完整分子的一电子抗还原 score，maximize |
| EA_raw | −Sred，使用一致电子参考约定 | 原始电子亲和量，minimize 时选集应与 maximize Sred 一致 |

`Gox_ensemble` 可作为 `Gox_free_ensemble` 的登记别名。气相 P1 和固定介质 P2 必须在字段中区分；旧 P1a 的电子能不得静默升级为 Gibbs 自由能。由分子自由能差转换为电极电势时，应单独记录电子参考、参考电极、溶剂和标准态约定，不能直接把 eV 数字标为某电极下的 V。

对每个候选 M：

\[
S_f=G_{M^+}^{ens}-G_M^{ens},\qquad
S_{Li}=G_{LiM^{2+}}^{ens}-G_{LiM^+}^{ens},\qquad
\Delta_{coord}=S_{Li}-S_f.
\]

还原副轴分别使用 M−/M 与 [LiM]0/[LiM]+，且需要电子束缚性和分子中心身份。历史 `unbound_anion` 只代表相应方法与协议下的 QC 结论，不能推广为所有方法下的普适物理事实。

## 7. WP1：方法审计与当前生产协议

### 7.1 审计设计

固定背景为 SMD(acetonitrile)、298.15 K、1 mol/L 溶液标准态。在同一介质、同一几何、同一状态下比较两个合理泛函与两个基组/弥散设置。8 分子×4 主态×4 设定形成 128 个单点审计上限；审计 SP 与 Opt、Freq 成本分开。

生产选择综合数值稳定性、QC 可用率、外部可比证据、排序敏感性与成本，禁止用更多翻转、更好看的 Top-k 或目标名单作选择依据。相关泛函差异是方法敏感性，不自动构成校准概率误差。

### 7.2 当前冻结设置

以仓库 `config/production_method_freeze_v1.json` 与 `config/physics_completion_v1.yaml` 的版本化记录为执行来源；当前登记为：

### 7.3 严格几何与 Hessian 验收

新生产、扩样和救援记录最终五项实际数值，要求全部满足：

| 准则 | 冻结上限 |
| --- | --- |
| 能量变化绝对值 | 2×10−7 Eh |
| 最大梯度 | 3×10−5 Eh/Bohr |
| RMS 梯度 | 8×10−6 Eh/Bohr |
| 最大位移 | 2×10−4 Bohr |
| RMS 位移 | 1×10−4 Bohr |

程序打印 CONVERGED 或 close-enough 不能覆盖最终数值超差。旧 TightOpt 结果仅按已登记的过渡政策保留；需要重提交或异常频率的腿进入新协议，并保留其来源。

NumGrad、NumFreq 与 AnFreq 分别表示数值一阶梯度、解析梯度有限差分 Hessian、解析 Hessian。2026-10-17 的全 cohort AnFreq 修订与配对审计作为当前采用依据；算法比较必须使用同一收敛几何、电荷、多重度、方法、模型项与网格。步长依赖、算法差异或虚频消失是诊断证据，不单独证明任一势面处处为真极小。

AnFreq 的模式、热化学、SMD/CPCM 模型项与警告都必须检查；内存与并行能力按实测配置。再次改变 Hessian 或热化学协议时，应统一修订目标 cohort，禁止只替换对目标名单有利的腿。

## 8. WP2：独立采样、同态系综与身份 QC

### 8.1 搜索与去重

四主态 M、M+、[LiM]+、[LiM]2+ 分别采样。母态结构可传播为起点，但带电态还需独立种子/扭转与 Li 给体 motif。初始廉价池保留最低能上方 6 kcal/mol 内的候选；首轮每态≤3 个独立生产结构，48 主态合计 48–144 个结构。

Li motif 枚举给体身份、单齿与几何可行的双齿，必要时补廉价 ESP 位点，按同一环境预优化。搜索父体、子 motif 与原子映射逐级登记哈希，不能换了父几何却沿用旧注册身份。

廉价筛选去重与生产 DFT 去重分开执行。生产去重必须包含 primary 和所有通过 QC 的 extra，在同一元素/拓扑保持映射下联合比较连接、Li 给体位点、重原子正旋转 RMSD 与可旋转键二面角。当前阈值登记为 RMSD<0.35 Å、扭转差<10°；具体键图、共价半径、转动键及镜像策略纳入协议。

仅允许正旋转重合；对真正的手性镜像还要检查映射后的手性，不能单凭 SVD 中间矩阵的行列式判断所有对都为镜像。映射搜索未穷尽、几何缺失或原子身份不明确时记 `dedup_blocked/mapping_unresolved`，不能默认为新极小。盆地 ID 规范化必须带分子、状态与父体作用域，并有路径/哈希证据，避免只剥前缀造成不同搜索池的 ID 碰撞。

### 8.2 3→6 审计与进一步扩池

EMC、DEC、DME、TMP 每态从真实首轮集合扩到最多 6 个独立结构；池中不足时报告真实池上限，不复制结构补足 6。DFT 弛豫回同一极小的搜索命中只计一次。

分别计算状态自由能变化、free/Li 氧化轴位移、pair gap、Top-k overlap 与 regret。ceiling 定义为首轮集合与已登记扩展集合的 QC 合格并集；尚有未处置成员时，正式全池 ceiling 保持缺失，允许另列清楚标记的部分结果。

按用户 2026-10-19 决定，本轮只报告差异，不判采样收敛。GFN2 的 1.00 kcal/mol 是筛选设置，不能转作生产级稳定性容差。独立数值重复误差或事先指定的实用分辨率冻结后，才进行新的采样稳定性评价；若已看过差异，则该容差属于有记录修订，需新数据复核或明确为敏感性分析。

冻结池耗尽仅说明该搜索协议无剩余候选；不能证明全局极小已找到。排序敏感且当前证据不够时，可版本化登记一次新的搜索池，记录新增搜索操作、预算、目标态、最大结构数和结束条件。不得通过无限续算或重命名同一起点制造“独立搜索”。

### 8.3 QC 与电子身份

每腿检查 SCF、五项几何阈值、完整模式/虚频、热化学、spin、波函数异常、连接、Li donor、fragment charge/spin、frontier localization 与必要的密度差。fragment 分区和阈值在审计集上登记，临界态增加另一分区或密度差证据。

结构完整性与电子局域化分别标记。`intact` 不自动等于 molecule-centered redox；Li-centered/mixed、ambiguous、断裂产物与无完整极小分开。纯 motif 切换在连接与目标身份仍合格时可作为条件结构响应；断键优化结果不自动代表反应路径、无势垒分解或真实溶液速率。

Hessian 与几何采用保持原子身份的刚体不变校验，允许合法平移/旋转，核对单位、完整模式、能量/热项来源及源文件哈希。AnFreq `.hess` 中的占位值不能替代原始输出中的实际电子能。

## 9. 自由能账本、数值常量与可用界限

### 9.1 单构象自由能

对同一溶液几何 q：

\[
G_i^{single}=E_{SP,sol}(q_i)
+\big[G_{thermo,sol}^{geom}(q_i)-E_{geom,sol}(q_i)\big]
+\Delta G_{std,i}.
\]

逐项保存 raw E、ZPE、thermal correction、低频处理、标准态与 G_single。E_SP 已包含隐式溶剂时不能再加一次同模型溶剂化能。使用同方法的能量与热项也须明确相减项，避免重复计电子能。

qRRHO 采用统一实现、版本、低频截断/阻尼、熵/焓处理规则并记录哈希；只写“qRRHO”不足以复算。缺少这些来源或需要更换热化学循环时，先补契约或另作 sensitivity。相同分子数的 redox 标准态项可抵消，但保留抵消说明；association/cluster formation 的分子数改变需要单独处理。

### 9.2 同态系综

\[
G_q^{ens}=G_{min,q}-RT\ln\sum_i g_i
\exp[-(G_{q,i}^{single}-G_{min,q})/(RT)].
\]

同一系综要求化学计量、电荷、目标身份、方法、环境、温度及热化学协议一致。各电荷态分别建系综，再相减形成 redox 标签；不同化学计量的 cluster 不做裸 G 混合。默认 g_i=1；重复搜索到同一极小不构成统计简并度。

统一常量：

| 常量或测试值 | 数值与单位 |
| --- | --- |
| R | 0.00198720425864083 kcal mol−1 K−1 |
| 1 Eh | 627.5094740631 kcal/mol；27.211386245988 eV |
| 1 eV | 约 23.06055 kcal/mol；96.48533 kJ/mol |
| RT，298.15 K | 约 0.59248495 kcal/mol，约 0.00094418 Eh |
| RT ln2 / RT ln3 / RT ln6 | 约 0.410679 / 0.650911 / 1.061591 kcal/mol |

常量应由单一源计算，禁止分别硬编码不同 RT。在 g_i=1 的有限 N 个已列成员中，校验：

\[
0\le G_{min}-G_{ens}\le RT\ln N,\qquad \sum_i w_i=1.
\]

RT lnN 约束的是当前已列、可比成员相对其中最低自由能的混合增益。它不约束未发现结构可能比当前最低结构低多少；N=1 的零界限也不能证明采样误差为零。`RT ln(N_new/N_old)` 只有在明确的权重/能量假设下才能用于额外混合项估计，不能普遍当成漏采样误差上界。

### 9.3 Li 配位机理辅助量

固定 R=DME，优先报告配体交换量：

\[
\Delta\Delta G_{bind}(M;R)=G([LiM]^+)+G(R)-G([LiR]^+)-G(M).
\]

这是相同分子数的交换反应，避免直接依赖裸 Li+ 的绝对溶剂化参考。它仍受模型、标准态和采样影响，也不是越强越好的性能分数。绝对结合量可保留作辅助诊断，并披露其单离子、腔体与平动熵限制。

## 10. 技术状态、科学状态与有界救援

计算状态链为生成→筛选→提交→SCF→几何→频率→身份→成员 QC。Slurm COMPLETED、ORCA 正常终止、成员 `computed`、态系综 `accepted`、分子四态 complete 是不同对象的状态，分别统计。

| 对象 | 状态或字段 | 规则 |
| --- | --- | --- |
| 一次执行 | JobID/array/restart/attempt | 唯一运行目录、不可变快照；失败与成本完整保留 |
| 成员 | computed / pending / technical_complete_qc_failed / superseded | computed 需全部成员 QC；superseded 只保留谱系、不重复权重 |
| 数值标签 | numerical_status | 有限且可复算的值可以存在，但不自动获得完整采样验收 |
| 态采样 | sampling_status | 区分仍有工作、预算/池受限、已完成登记协议 |
| 态验收 | accepted / provisional / limited / blocked | accepted 仅表示登记协议下的合格验收，不等于全局采样收敛 |
| 合规项 | satisfied / partial / exempt / not_satisfied / blocked 等 | exempt 需要理由、零对象或限制证据，不能伪装科学通过 |

救援按原因路由：技术错误先诊断运行环境；已收敛但五项阈值超差从自身末几何严格重优化；max_cycles 从可复算且身份一致的轨迹帧有界续算；显著虚频先核验严格收敛与模式，再按已登记预算选择模式或独立结构。起点或末帧已发生物种漂移时停止该末帧路径，不以重试恢复另一个分子的身份。

预算区分技术重试、科学重优化、搜索新池，分别记实耗和谱系。已有预算上限或第三次例外必须逐成员登记理由、生效范围和最后一次条件，不因技术重试免费就无限执行。已提交未回收的成员仍由在途包拥有，禁止重复建包或重复提交。

新旧输出归档统一以原始字节 SHA256 核验，幂等回收比较字节，避免 Windows 换行归一化改变哈希。每次回收包含输入、起点、末几何、log、Hessian、stderr、调度记录、起止时间及实际可用轨迹；缺项须写原因。源 canonical 变更时同步变更证据映射与归档，不能只换账本路径。

## 11. WP3：独立敏感性与决策指标

### 11.1 pair 证据

对模型或条件态 m、合理方法 r，记候选差 D_ij^(m,r)。由预先接受的方法范围、明确的数值容差及有依据的采样敏感性构造保守区间 I_ij^m。方法、数值和采样来源分别登记；没有校准依据时不做概率解释或默认平方和合并。

若 I 全部高于 +δ，判 i>j；全部低于 −δ，判 i<j；其余为 unresolved。两模型都解析且方向相反才为 ROBUST_INVERSION，同向才为 STABLE；身份不合格和证据缺失单列，不能用零差填充。不能从被比较 free/Li 位移本身估计它的误差，再用同一差检验自身翻转。

同时报告 N_all、N_eligible、N_resolved_both、N_inversion、N_unresolved。主稳健翻转比例为 N_inversion/N_resolved_both，另给全 pair 分母比例，分母为零时报告 NA。n=12 全 pair 数为 66。审计只覆盖特定 pair/方法时，不能把结论默认为全体已独立认证。

普通 Kendall τ_b 基于原始可比标量和真实 ties；未解析 pair 一般不具有传递性，不能任意合并成等价类或 τ_b 的 ties。偏序仅取已解析且无冲突的关系；其余保留为未解析图。方法 spread 的 z 曲线、bootstrap 与 GPR posterior ordering probability 分别命名，不把相关泛函当独立重复或把 1.96×spread 写成已校准 95% CI。

### 11.2 选集与 regret

n=12 主 k=3、辅助 k=2/4。比较层级时使用相同 cohort，逐层报告排除表；n<2k 时标记选集证据不足。四分子采样审计另用固定 k=2、辅助 1/3，并保留与主分析不同的作用域。

\[
O_k=|S_T(k)\cap S_M(k)|/k,\qquad
J_k=|S_T(k)\cap S_M(k)|/|S_T(k)\cup S_M(k)|.
\]

最大化目标的主 regret 为：

\[
R_k^{mean}=\frac1k\sum_{i\in S_T(k)}y_i-
\frac1k\sum_{i\in S_M(k)}y_i.
\]

另可报告 `best_selected_regret = max(y_all)−max(y_selected)`，但它只衡量是否选中一个好候选，与整个 Top-k 集合均值损失不同，不能继续共用 `R_3` 名称及 0.10 eV 验收门槛。最小化目标先统一效用方向；边界 ties 使用预登记、与隐藏真值无关的 ID 次序，并报告敏感性。

若 limited 候选可能跨越 accepted-only 的 Top-k 边界，只能报告该 accepted 子集排序和包含受限候选的可能选集；不能把 accepted-only Top-k 当全 12 分子的已认证 Top-k。若缺少有效误差界，区间上/下界应为未知，不把 RT lnN 直接当成对未发现极小的认证界限。

外部阈值决策错误仅用于事先明确的设计标准或实验阈值。0.10 eV 是计算目标下的回放容许损失，不是实际电池工程阈值。

### 11.3 机制案例与旧翻转阶梯

逐级比较 vertical→adiabatic E→G_single→G_ensemble，以及固定背景 free→Li 条件变化。旧 12 格阶梯为两对×六级，筛选层 R4_screen 与生产层分开统计；limited/provisional 有数值时也不能计入 computed。

案例最多 3 个：优先稳健翻转，再选 Top-k 未解析边界，最后选身份改变。每例提供原始结构、密度/自旋、配位变化、E/G 分解、方法敏感性和选集影响六项证据。没有稳健翻转时使用边界或限制案例，不补造翻转故事。

描述符限预列 donor type、chelation、flexibility、functionalization、廉价 ESP；TPSA 等额外关联标为探索性，完整报告检验与多重比较。12 分子不拟合多参数机理模型，也不把计算成本与翻转的相关关系解释为因果律。

## 12. WP4：外部锚点与有效性限制

分别审计气相 vertical/adiabatic IP/EA 和固定条件溶液数据，保留原文页码、表号、量定义、参考电极、溶剂、盐浓度、温度、扫描速率、onset/峰值、测量不确定性与系列身份。

分级为 tier 1 可定量、tier 2 仅可比系列趋势、tier 3 不适于当前目标验证。不可逆分解 onset 不直接等同完整分子平衡氧化自由能；7 分子形成的 21 pair 也不是 21 个独立实验样本。

按既定检索尝试寻找 6–10 个新增可比条目，数量是工作目标而非造数任务。没有 tier 1 时保留 `validation_limitation`：所研究的排序是 computational target；不据此声称溶液量被定量验证。外部限制可作为当前报告的终态，未来若有合格新证据，创建新版本审计而不覆盖旧 NOT CLOSABLE 结论。

所有还原对象按规则被排除且合格对象为零时，相关三项还原检查可为 exempt，并保存零对象清单；新纳入任何合格对象时豁免自动失效。原文障碍/不适用也必须留证，不能仅用“付费墙”代替已经可取得证据的审计。

## 13. WP5：目标一致的 Δ-learning 与主动查询

### 13.1 A/B 目标与特征成本

| 任务 | 目标 | 可用特征 | 成本契约 |
| --- | --- | --- | --- |
| A：free | 预测 S_f=Gox_free_ensemble | X0 与廉价 P0；target-proximal 特征单独列情景 | 包含候选筛选与取得 free 两态合格标签的真实消耗 |
| B：conditional shift | 预测 Δ_coord=S_Li−S_f，恢复 S_Li=S_f+Δ̂_coord | 已取得并计费的 S_f、X0 与合法 X1 | free 标签与 X1 成本计入；Li 两态查询、失败、救援及共享成本按谱系去重 |

任务 B 同时保存 `free_label_ev`、`li_label_ev`、`coordination_shift_ev`，测试 `li = free + shift`。仅计算 Li 两态之差得到的是 S_Li，不是 coordination_shift。直接预测 S_Li 与预测 shift 后恢复 S_Li 在相同可见信息、split、特征和调参预算下比较。

X0 是 query 前廉价描述符、P0、cheap ESP 与柔性；X1 是已支付 free 分子 DFT 后可获得的信息；X2 包括 Li-complex DFT 几何、charge redistribution、交换量等，只作机制解释。不得用 X2 证明未做 Li 查询就能廉价预测 Li 目标。

主模型采用已冻结 ridge/KRR 与 GPR；random、group/scaffold 和 LOFO 结果分别报告，同一分子的所有构象与状态在同一 split 中。预处理和调参位于训练/可见集合内部；小样本不支持复杂模型优劣的普适结论。

### 13.2 数据准入与工作流演示

确认性回放以 12 个完整合格目标为计划池。数值存在但任一目标腿 limited/provisional 的分子不能静默进入“完整 QC 标签池”；可输出受限目标敏感性或 accepted 子集演示，并列出 cohort、边界和样本不足。

### 13.3 四策略与可见性

每个任务初始 4 标签、每轮 1 标签、20 配对 repeat。比较 random、diversity、uncertainty、ranking_aware。任务+repeat 决定同一初始集合；策略内部随机性另派生稳定 SHA256 种子。

Acquirer 只拿可见标签和已付费特征；独立 Evaluator 持有隐藏真值。每轮先训练、预测并冻结 acquisition，再揭示查询结果；全向量只允许 evaluator 使用。acquisition 不得读取包含隐藏真值的候选导出表。盲性测试包括改变隐藏标签后、在可见标签相同条件下 acquisition 决定保持一致，而非只检查成员变量名称。

uncertainty 使用可见训练数据拟合的模型不确定性并检查其有限样本校准；ranking_aware 使用模型 posterior 中候选入 Top-k 的概率/熵或等价已冻结准则，不使用真实 top-k。无校准依据时分别报告模型分散度与准确性限制。

### 13.4 指标、停止规则与成本

逐轮保存 task、model、strategy、repeat、初始集合哈希、候选、可见标记、预测、选集、n_T、失败/重试、τ_b、O_3、主均值 regret、未查询 MAE/max error 和累计成本。评价同时给“全池选择”（已查样本用真标签、其贡献单列）与“只看未查样本的泛化误差”。

新版本主成功事件为 O_3≥2/3 且 R_3^mean≤0.10 eV，τ_b≥0.80 作辅助。所有阈值在本版本回放前冻结，并保留完整连续曲线；最有信息的末轮均值不替代经验停止预算。

核心原文“16/20 在两个连续预算点达标”在 v3 新协议明确为：同一批 20 repeats 中，至少 16 个 repeat 在 n 和 n+1 两点都成功；两个点都要求 n_T<N_pool。报告的停止预算为 n+1。它比仅分别统计每点≥16 更明确，旧实现若采用后者保留为旧口径并重算新结果，不能静默混用。

预算点缺失、重复、pool 不同、非有限指标或 repeat 不齐时不得报通过。池耗尽后的完美选择不是未查询恢复能力。未达到标准则报 `not_reached`，没有完整目标池则报 `blocked_target_pool`；不能用最终端点 20 次平均值达标替代。

成本主表记录实际 allocated cores×wall-hours，并包含初始四标签、后续查询、失败/救援、free 前置、特征和共享作业。墙钟、allocated core-hours 与 process CPU time 分别命名。假设 0.6/查询等只能为 `ASSUMED_CONSTANT` 情景；查不到 job-query 关联时为 MISSING，不转成实测零成本。跨策略复用历史运行成本是反事实 replay 成本模型，需解释测量与模拟的边界。

## 14. WP6：共同背景显式配体检查

门槛保持为 Li 配对 complete≥9/12 且生产系综 accepted=48/48。门前 WP6 可选且 blocked；两项同时满足后升级为计划内工作。不同的限制收口状态不能替代 accepted 计数。

R=DME，在 EC、DME、AN、TMP 上比较 [LiM]+/[LiM]2+ 与 [LiMR]+/[LiMR]2+ 的 redox 差值；各态独立弛豫、采样与身份 QC，DME 对应 [Li(DME)2]。统一背景、温度和热化学约定。

在同一化学计量内建系综，再计算 redox 差，最后比较两个条件下的 redox 量。不同配体数 cluster 的裸 G 不混合，不把这一 check 解释为真实配位概率；它只检验少量关键结论对一个共同显式配体的敏感性。
