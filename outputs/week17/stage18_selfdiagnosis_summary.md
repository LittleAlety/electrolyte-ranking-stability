# Stage 18 / Week 17 · Part B — 零额外成本的自诊断
**一句话结论**：输了（样本外）：`gap_warn_value` 在发现集上看着不错（LOO 0.917 > 基线 0.911，精确 p = 2.56e-19），但在真正留出的 54 格上只到 0.796、输给多数类基线 0.907（TP=0, FP=6）。这正是 Week 15 的教训重演 —— 池化发现集上的漂亮数字不是可用的预警。
## 命题与方法
- 命题：只读**默认臂那一个 `.out` 已经打印出来的字段**，能否看出它停在了高解（`moread_lower`）？不需要任何额外量子化学作业。
- 数据：发现集 `outputs/week15/stage16_cells.csv`（360 行 / 32 正例）；留出臂 `outputs/week15/stage16_validation_cells.csv`（54 行 / 5 正例：DEC/EA/FEC/MA/TEGDME/VC）。标签 `classification == "moread_lower"` ⇔ `delta_ev < -1e-3 eV`。
- 特征（全部零额外成本）：SCF 迭代轨迹（圈数、ΔE 轨迹、最终 DIISErr/MaxDP/RMSDP）、ORCA 自己的 Small HOMO/LUMO gap 警告（含符号与次数）、Stage 17 的身份指标（<S**2>、spin_max、spin_pr、n90、自旋中心、约化轨道通道及其 Löwdin 版）、轨道能量块（HOMO/LUMO/gap）。
- 协议逐条镜像 `scripts/build_stage16_predictor.py`：只用发现集筛特征 → 冻结一条规则 → 样本内/LOO/多数类基线 → AUC 精确零分布 → 留出臂打分 → 事后按态分层 → 多变量上限。

## 冻结规则（方向与阈值已写进 JSON，可原样复现）
- 特征 `gap_warn_value`：signed gap in Eh quoted by the warning; +1.0 when the warning did not fire (a large gap is the healthy case)
- 方向 越小越危险（<= 阈值判正），阈值 `-0.0395`。选择依据＝发现集 `|AUC-0.5|` 第一名（Stage 16 同口径）；阈值取使全发现集普通准确率最大的切点。
- 缺失口径：该特征在发现集缺 122 行，按 1 填充（ORCA 未报警＝gap 大＝安全）。

## 显著性（AUC 的精确零分布）
- 方法 `exact_mann_whitney_dp`：U 是 AUC 的单调函数，其零分布按 tie-aware 中位秩用动态规划精确算出（70637 个 DP 状态 / 19854825 次操作）；观测 AUC=0.0840，**精确 p = 2.561e-19**（全部指派 C(360,32)=5.82e+45）。
- Monte-Carlo 交叉核对（`method="monte_carlo"`，20000 次抽样，seed=20261001）：p = 5e-05；与精确值同量级，但它**不是**精确值。

## 单边筛查：负 gap 警告是漏解的必要条件（post_hoc）
- 必要条件成立且样本外可迁移：37/37 个漏解都带 ORCA 的 Small HOMO/LUMO gap 警告（发现集 32/32、留出臂 5/5），P(无警告 | 漏解) = 0.000；正例的带符号 gap 全为负（发现集 -0.047 ~ -0.03、留出臂 -0.03 ~ -0.013）。
- 反向不成立：发现集 206/328、留出臂 31/49 个负例同样报警 ⇒ 有警告**不是**充分条件，这正是 value 阈值规则样本外失效的根因。
- 分层条件概率 P(漏解|有警告)：发现集 cation 0.134 / anion 0.134，留出臂 cation 0 / anion 0.278；凡有样本的层里 P(漏解|无警告) 的最大值为 0.000（138 个中性分子全部无警告且全部 coincident）。
- 同一 414 对口径的权衡：`只要求有警告` 敏感度 1.000/1.000、特异度 0.372/0.367、准确率 0.428/0.426（涨不过基线）；冻结规则 `gap_warn_value <= -0.0395` 发现集敏感度 0.406、留出臂敏感度 0.000 ⇒ **必要条件可迁移、充分条件不可迁移**。覆盖与限制：警告对全部 414 对可测（含 138 个无自旋块的闭壳中性），不受身份指标缺失限制；但结论仅由 37 个正例支持（留出臂 5 个、全为 anion）。

- 有缺失的特征列（行数）：scf_final_diiserr 2/414；gap_warn_value 140/414；s2 138/414；spin_max 138/414；spin_pr 138/414；spin_n90 138/414；loewdin_spin_max 138/414；loewdin_spin_pr 138/414；loewdin_spin_n90 138/414。
- 缺失原因：闭壳中性分子不打印自旋块（s2 / spin_* / loewdin_spin_* 各缺 138/414）；gap_warn_value 缺 140/414＝ORCA 未报警（gap 大），按 +1.0 Eh 填充；scf_final_diiserr 缺 2/414＝该 run 无 DIIS 块。
- Löwdin 原子自旋的约化轨道子块未解析（Stage 17 只有 MULLIKEN REDUCED ORBITAL 解析器）→ 没有 loewdin_orbital_abs。
- 只解析 alpha 块 → 没有 beta (SPIN DOWN) 的 HOMO/LUMO。
- 自旋中心/轨道通道是字符串（如 C0、N2 s），无序，只进 CSV，不参与 AUC 筛选。
## 局限
- 标签只对开壳层（cation/anion）有定义；120 个中性格天然是负例，把池化多数类基线抬到 0.911，所以池化准确率本身信息量很低。
- 留出臂只有 5 个正例，留出 accuracy 的分辨率是 1/54 ≈ 0.019，任何 1-2 个格子的差别都可能是噪声。
- 精确零分布用的是 tie-aware Mann-Whitney U；它假设行之间可交换，忽略分子内的格子间相关（同一分子的 9-10 个 epsilon 并不独立）。
- 特征来自已算完的默认臂 `.out`，因此这是一次**事后诊断**，不是事前预报；它的价值在于省掉第二次计算，而不是省掉第一次。
- 发现集与留出臂的分子不同（12 vs 6），但都在同一套 r2SCAN-3c/C-PCM 协议下，方法学外推没有验证。
- 筛选表里的留出列只作事后展示：确有其它零成本特征（例如 orbital_abs）在留出臂上同时胜过基线，但它们是在看到留出臂之后才被挑出来的，不构成证据；冻结规则只能看发现集。
- 单边筛查那一节只证明『警告是漏解的必要条件』，不构成事前预报：ORCA 的 gap 警告在 run 开始前就打了，它标的是体系难度而不是收敛到的解；把它反读成『必然漏解』是误用（负例假阳性率见 JSON 的 one_sided_screening.specificity）。
