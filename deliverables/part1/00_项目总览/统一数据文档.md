## 一、项目定位与核心结论

**一句话定位**：在刻意做小的分子集（core set 18 分子 / broad pool 40 分子）上，用两种方法（GFN2-xTB 廉价代理与 ORCA r2SCAN-3c 电子结构）研究「从廉价代理到更真实的电子结构 / 环境模型」的每一步改变，是**只会平移数值**还是**会真正翻转材料筛选决策**，并给出翻转背后的物理机制与最小算力预算。

**核心结论（8 条）**

1. **值误差 ≠ 排序误差**（项目最反直觉的一条）。三臂对同一批气相锚点：r2SCAN-3c 垂直 IP 的 MAE = 0.251 eV、Kendall τ_b = 0.727；GFN2-xTB ΔSCF 的 MAE = 4.481 eV（约前者的 18 倍）却拿到更高的 τ_b = 0.911；Koopmans P0 的 MAE = 1.377 eV、τ_b = 0.689。来源：`docs/10_week4_report.md` §2.3、`outputs/week4/p1_anchor_comparison.json`、`outputs/figures/F3_value_error_vs_rank_error.png`。
2. **决定一级台阶会不会改写排序的是位移的「离散度」（std），不是位移的「大小」（|mean|）**。10 个 (台阶, 轴) 数据点上 ρ(std, τ_b) = −0.851，而 ρ(|mean|, τ_b) = −0.535；同一组里 ρ(std, f_unresolved) = +0.894。来源：`outputs/week9/stage10_ladder.json`、`outputs/week9/stage10_summary.md`、`outputs/figures/F19_stage10_ladder.png`。
3. **pair 分辨率的经验量 σ_ij 有闭式解**：σ_ij = |d_i − d_j| / √2（d = 逐分子层间位移），于是 resolved/unresolved 判据化简为**一条无量纲判据** `q_ij = |d_i − d_j| / |P_i − P_j| ≤ √2 / z`，临界值 1.414（z = 1.0）/ 0.722（z = 1.96），可在花钱之前预判。来源：`outputs/week10/stage11_sigma_anatomy.json`、`docs/20_week10_report.md` §0。
4. **介电层几乎免费**。裸 CPCM 的介电响应是 Born 形式 δ(ε) = S·(1 − 1/ε)，在 24 条 (分子, 轴) 曲线上 mean R² = 0.9861（Onsager 0.8779，21/24 条胜出），两参数族的自由参数被压回 k = 0.0779 ± 0.1004；残余满足 |dE|·ε ≈ 2.1 eV 幂律，ε = 200 时残余最大 19.62 meV（PC/anion），仅氧化轴 δ_m（700.2 meV）的 2.80%。来源：`docs/22_week12_report.md` §0、`outputs/week22/dielectric_limit.json`、`outputs/week12/stage13_analysis.json`。
5. **配位位移是全部台阶里最大的一级，且与「饱和一致」**。C1 = [LiM]⁺ 的 ΔIP = +4.839 ± 0.541 eV / ΔEA = +6.615 ± 0.738 eV（n = 12），C2 = [Li(M)₂]⁺ 降到 +3.171 ± 0.499 / +5.410 ± 0.544 eV，第二个配体增量 ΔΔIP = −1.669 ± 0.247 eV、ΔΔEA = −1.205 ± 0.303 eV；C1 → C2 的 τ_b = 0.697–0.911、Top-10% 重叠全为 1.000、f_robust_inv = 0。来源：`outputs/week8/stage9_summary.md`、`outputs/week8/stage9_shell_shifts.csv`、`outputs/week23/shell3_xtb_sign_test.md`。
6. **「第二个 SCF 解」是真实的另一个电子态，但只由昂贵方法定义**。全目录 414 对（发现集 360 + 留出臂 54）中可测 276 对，冻结判据 `charge_l1 > 0.039` 在可测子集上 AUC = 1.000000（tp/fn/fp/tn = 37/0/0/239）；但「零额外成本自诊断」在留出臂输给多数类（0.796 vs 0.907，TP = 0），唯一站得住的正面结论是单边筛查「无警告 ⇒ 安全」。来源：`outputs/week17/stage18_identity_census.json`、`outputs/week17/stage18_selfdiagnosis.json`、`docs/27_week17_report.md` §0。
7. **漏解（默认初猜停在高解）可被已有容差吸收，也可被安全靶向**。两个轴上漏解的最大效应量 A_axis = 0.1523 eV（氧化，TMP@ε=5）/ 0.2860 eV（还原，EMC@ε=1000），分别是冻结 δ_m 的 21.7% / 13.8%；靶向双腿抓住全部 19/660（氧化）与 21/660（还原）次真实翻转、0 漏，但只省 28.3% / 3.3% 算力；只保护 Top-1 清单边界的变体才省 91.7% / 83.3%。来源：`outputs/week23/targeted_two_guess.json`、`outputs/week23/targeted_two_guess.md`、`outputs/figures/F45_targeted_two_guess.png`。
8. **0.02 Å 的 RMSD 一刀切在 0.021–0.100 Å 临界带上会误判**。真 NEB（climbing: no）取代直线插值后，Stage 19 判为 `distinct_lower` 的 EC/cation/ε=5 一格峰高只有 0.141 meV（直线界 4.245 meV 的 1/30）≪ k_B T = 25.7 meV，两端点其实是同一个盆地。来源：`outputs/week22/neb_refinement.json`、`outputs/week22/neb_refinement.md`、`outputs/figures/F44_neb_refinement.png`。
