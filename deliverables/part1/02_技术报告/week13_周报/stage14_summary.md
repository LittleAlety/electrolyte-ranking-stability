## 0. 一句话结论

Week 12 把环境位移拆成了四项，但只把「畸变项」当成了一个已量化的数，没有解释它；
同时留下了一个未裁决的离群点（EMC 还原轴 Born R² = 0.8468）。本周把两件事一起做完：

1. **畸变项有了逐态的物理身份**：`dist_ev` 不是一项，而是**两个单态畸变惩罚之差**
   （`dist_ox = D_cation − D_neutral`、`dist_red = D_neutral − D_anion`），
   该恒等式在 192 个「分子 × 层」行上重建，最大残差 **6.7e-12 eV**。
   逐态看，**72/72 个惩罚全部为正**（最差 +0.0113 eV），这是变分检验该有的符号。
2. **通道不对称是「阴离子效应」**：`D_anion = 0.3710 eV`，对 `D_cation = 0.1120 eV`、
   `D_neutral = 0.0685 eV`。还原轴与氧化轴的位移之比 **6.95 倍**，
   且还原轴 **12/12 个分子为负**，氧化轴只有 8/12 为负——
   即：**氧化轴的小均值是三个分子（EC/TMP/PC）撑起来的，不是全体行为**。
3. **归因只成功了一半**：唯一稳健的关系是 `D_neutral` 对分子自身偶极矩
   （Spearman rho = **+0.909**，p = 4.2e-05，留一 R² = **0.634**）。
   **阴离子惩罚无法用仓库里任何已存描述符预测**（最佳留一 R² 仅 **0.162**），
   而它恰恰是产生 6.95 倍不对称的那一项。这是一个**否定性结果**：
   需要的描述符是「新增电子的空间弥散度」，现有量都不测它。
4. **Week 12 §14 的那对均值是错的**：文档写的 (−0.0465, +0.3272) eV 在
   510 种「层子集 × 符号」聚合里 **0 命中**；可复现值是 **+0.0435 / −0.3025 eV**
   （逐分子先平均，6 个 bare CPCM 层）。
5. **EMC 离群点裁决 = `solution-selection artefact`（解选择伪影）**，
   不是粗网格、也不是数值噪声。**证据来自独立观测量（偶极矩），不是能量自证**：
   EMC 阴离子的偶极在九个介电点上于两组值之间**交替跳变 4 次**
   （~2.5 D 分支 vs ~6.3–7.1 D 分支），粗糙度 **1.99**，而光滑总体中位数仅 **0.235**；
   12 个分子里只有 EMC 的 `EA(eps)` 二阶差分异常（0.537 eV，其余 ≤0.148 eV）。

## 1. Part A：畸变项的定义与恒等式

`bare` 定义为

```
bare(X, t) = Total Energy(X, t) − CPCM dielectric − SMD CDS
```

即在**同一次自洽计算**里把两项环境贡献摘掉之后的电子能量（几何不变，密度变）。
逐态畸变惩罚与轴观测量：

```
D_态(t)          = bare(X, t) − bare(X, gas)          (>= 0，变分要求)
dist_oxidation   = D_cation − D_neutral
dist_reduction   = D_neutral − D_anion
```

符号口径：`dist_ev` 存为**对环境位移的一项贡献**，故

```
d_total_ev = diel_ev + dist_ev + cds_ev + d4gcp_ev + residual_ev
```

该五项恒等式在全部 **216 行**上残差**恰为 0**（不是「小于某个阈值」，是精确 0，
因为 `residual_ev` 就是按定义反解出来的兜底项）。
两条恒等式的残差见 `correction.identity_max_abs_residual_ev` 与
`correction.penalty_identity_max_abs_residual_ev`。

## 3. 通道不对称：还原轴 6.95 倍于氧化轴

把 `dist_ev` 先对六个层平均、再对 12 个分子平均（避免把 6 个层当成 6 个独立点）：

| 轴 | mean (eV) | std | median | min | max | 为负的分子数 |
| --- | --- | --- | --- | --- | --- | --- |
| oxidation | +0.0435 | 0.1134 | −0.0065 | −0.0487 | +0.2939 | 8 / 12 |
| reduction | −0.3025 | 0.2369 | −0.2148 | −0.7591 | −0.0387 | 12 / 12 |

不对称比 = |reduction| / |oxidation| = **6.95**。

**氧化轴的小均值是「相消」的产物，不是「小效应」**。逐分子看：

| 分子 | dist 氧化 | dist 还原 |
| --- | --- | --- |
| EC | **+0.2939** | −0.6558 |
| TMP | **+0.2096** | −0.1460 |
| PC | **+0.1689** | −0.7591 |
| SN | +0.0122 | −0.0387 |
| DMC | −0.0058 | −0.1156 |
| DOL | −0.0060 | −0.2030 |
| DME | −0.0070 | −0.5431 |
| EMC | −0.0094 | −0.3289 |
| SL | −0.0187 | −0.3876 |
| AN | −0.0267 | −0.2266 |
| DMSO | −0.0399 | −0.0829 |
| GBL | −0.0487 | −0.1432 |

氧化轴正负混杂（8 负 4 正），把均值压到 +0.0435；还原轴则整齐地全负。
**「畸变把环境位移拿回多少」在氧化轴上是一个分子依赖的性质，不能报一个均值了事。**

## 4. 归因筛选：14 个描述符 × 5 个目标，n = 12

打分用**留一交叉验证 R²**（不是拟合 R²，因为 n = 12 且只有 1 个自变量）。
每组 12 个独立点（每个分子一个点，六个层先平均），因此不存在层间伪重复。

| 目标 | 最佳描述符 | Spearman rho | p | 留一 R² | 结论 |
| --- | --- | --- | --- | --- | --- |
| D_neutral | `mu_neutral_debye` | **+0.909** | 4.2e-05 | **0.634** | 唯一稳健 |
| D_cation | `homo_ev` | −0.406 | 0.19 | 0.071 | 不可预测 |
| D_anion | `mu_anion_smd_acn_debye` | +0.629 | 0.028 | 0.162 | 不可预测 |
| dist_oxidation | `homo_ev` | −0.664 | 0.018 | 0.120 | 不可预测 |
| dist_reduction | `mu_anion_smd_acn_debye` | −0.427 | 0.17 | 0.075 | 不可预测 |

三点读法：

- **中和态的畸变就是「溶剂把极性分子重新极化」**：`D_neutral` 正比于分子自身的
  气相偶极矩，斜率 0.0154 eV/D，截距 0.018 eV。物理上这是 Onsager 反应场对
  永久偶极的再定向/再极化代价，量级合理。
- **`D_anion` 的最佳描述符留一 R² 只有 0.162**，而且**阴离子自身的偶极矩几乎无关**
  （rho 仅 +0.062，p = 0.61，已单独核验）。唯一有点相关的是**在 SMD 乙腈里测到的
  阴离子偶极**（rho +0.629）——也就是说，**「电子加进去后溶剂里长什么样」比
  「气相里长什么样」更能说明畸变代价**。这本身是一条机制线索。
- **两个轴观测量都不可预测**（最好留一 R² < 0.4）。氧化轴的 `homo_ev`
  rho = −0.664（p = 0.0185）看着像信号，但留一 R² 只有 0.120，
  在 n = 12 上**不能当预警器**（Week 11 的预警协议不应接入它）。

## 5. Week 12 §14 的均值被证否

`docs/22_week12_report.md` §14 写的是「氧化 −0.0465 eV 均值 / 还原 +0.3272 eV 均值」。
Stage 14 做了**穷举证否**：把 8 个环境层（cpcm 5/10/20/40/80/200 + smd 乙腈/水）
的所有 2^8 − 1 = 255 个子集 × 2 个符号（`+dist_ev` / `−dist_ev`）共 **510 种聚合**
逐个算，要求同时在两轴上匹配到 1e-6 eV：

- 精确命中 **0 个**；
- 最接近的是 `cpcm_10 + cpcm_20 + cpcm_80 + smd_water`、符号 `−dist_ev`，
  给出 (−0.04646, +0.32842)，**仍差 1.22 meV**。

也就是说 §14 那对数字**不是任何可复现聚合的结果**，是草稿中间值泄漏进了报告。
可复现值（也是本周全部结论采用的）：

```
oxidation = +0.0435 eV   (std 0.1101)
reduction = −0.3025 eV   (std 0.2548)
SMD 乙腈对照：oxidation = +0.0839 eV, reduction = −0.3567 eV
```

（`oxidation_std_ev` / `reduction_std_ev` 是在**全部 72 行**上算的，所以含层间离散度 0.1101 / 0.2548；
§3 表的 0.1134 / 0.2369 是**先对六个层平均得到 12 个分子值**再算 std。两者均值完全相同，只有离散度口径不同，均在 JSON 里留档。）

## 6. Part B：EMC 离群点诊断（63 个新作业，0 失败）

### 6.1 动作与可复现性

在 Week 12 的六个 bare CPCM 层（5/10/20/40/80/200）中间插入 **5 个新介电点**
（eps = 7/14/28 + 40 与 200 之间的加密由 Week 12 已有层承担），得到九点阶梯

```
eps = 5, 7, 10, 14, 20, 28, 40, 80, 200
```

只对 **EMC / DMC / EC** 三个分子 × 3 个电荷态重跑 = **63 个作业，全部 ok、0 失败**
（并发 `--jobs 2 --nprocs 8`）。几何一律**复用 G1，不重新优化**。

**四个共享介电点（5/10/20/40）的复现性完美**：36 个能量与 Week 12 冻结值
**逐位字符串一致**，`max |ΔE| = 0.000e+00 Eh`，QC flag 全空。
回归守卫：本脚本的 Born 机器**精确复现** Stage 13 的 R² = 0.8468 / slope = 2.5668（六点冻结网格）。

### 6.2 加密让 EMC 变得更糟，而不是更好

| 曲线 | 六点 R²（Stage 13） | 九点 R²（本周） | 符号变化数 6→9 点 |
| --- | --- | --- | --- |
| **EMC / reduction** | **0.8468** | **0.6788** | **2 → 4** |
| DMC / reduction | 0.9985 | 0.9984 | 0 → 0 |
| EC / reduction | 0.9613 | 0.9590 | 0 → 0 |
| EMC / oxidation | 1.0000 | 1.0000 | 0 → 0 |
| DMC / oxidation | 1.0000 | 1.0000 | 0 → 0 |
| EC / oxidation | 0.9891 | 0.9889 | 0 → 0 |

**「采样不足」被直接排除**：如果是网格太粗，加密应该改善拟合；实际 R² 掉到 0.6788，
非单调跳变从 2 次增加到 4 次。其余五条曲线纹丝不动。

拐点在 **eps 10 → 20 的单跳 −0.0631 eV**。逐态分解：

```
neutral  −0.0135 eV
cation   −0.1199 eV
anion    +0.0496 eV        （还原轴 delta = 中性项 − 阴离子项）
```

### 6.3 ★ 决定性证据：偶极矩揭示「解选择伪影」

能量曲线的形状本身不足以定性（那会变成用能量自证能量）。我们改用**一个与能量无关的
独立观测量**——ORCA 打印的偶极矩——去筛查全部 36 条「分子 × 态」偶极阶梯：

**EMC 阴离子的偶极按 eps 的序列（D）：**

```
5 → 2.538    7 → 6.300    10 → 6.647   14 → 6.870   20 → 2.499
28 → 7.145   40 → 2.542   80 → 2.556   200 → 2.564
```

**两个 SCF 解在交替**：低分支 ~2.5 D（5/20/40/80/200）与高分支 ~6.3–7.1 D
（7/10/14/28），九点里**跳变 4 次**。而能量与偶极的跳变**同相**。

粗糙度（`max|二阶差分| / span`）对照：

| 序列 | 粗糙度 |
| --- | --- |
| **EMC / anion** | **1.99** |
| DMC / reduction | 0.069 |
| EC / reduction | 0.085 |
| 光滑总体中位数（36 条里其余 35 条） | 0.235 |

**36 条偶极阶梯里只有 1 条可疑，就是 EMC/anion**；EMC 的中性态与阳离子态偶极完全光滑。

**独立佐证**：把 `EA(eps)` 的二阶差分铺开到 12 个分子上，EMC = **0.537 eV**，
其余 11 个全部 ≤ **0.148 eV** —— EMC 是唯一的离群。

### 6.4 裁决

> **EMC 还原轴的离群点 = `solution-selection artefact`（bare CPCM 的 SCF 解选择伪影），
> 不是粗网格，也不是数值噪声。**

物理读法：EMC 阴离子在极化连续介质里有**两个能量接近的 SCF 解**（对应阴离子电子密度
「贴在内侧」还是「铺到外侧」两种形变）。介电常数改变腔外屏蔽，二者能量次序在
eps ≈ 10–20 之间翻转，于是 ORCA 每次落到不同的解上，求出的 `EA(eps)` 就出现锯齿。
**这是「一个分子的一条曲线」的局部事故，不构成对 Born 形式的反例**——
同族的 DMC、EC 还原轴 R² 都在 0.96 以上。
