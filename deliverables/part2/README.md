## 五、重组说明（2026-10-15）

| 项 | 重组前 | 重组后 |
| --- | --- | --- |
| 分组维度 | `week28` … `week44` 共 17 个周目录 | 9 个「成果种类」目录 |

- 去重前逐文件比对了 sha256：**同一周内相对路径在不同周之间内容零冲突**（仅 `README.md` / `SHA256SUMS` / `verification.json` / `SUBMISSION.json` 这 4 类按周元数据本就不同），因此去重不丢信息、不改字节。
- 全量核验：迁移过来的 387 个载荷文件的 sha256 集合，与重组前的 376 种唯一内容**逐一相同**——`旧有今无 = 0`、`今有旧无 = 0`，即**零字节改动、零内容丢失、零凭空新增**。
- 删除的只有按周目录本身（内容已全部落位到新结构）与旧的顶层 `README.md`（已原样归档为 `09_校验与清单/历史/原顶层README_按周索引.md`，信息并入本文件）。
