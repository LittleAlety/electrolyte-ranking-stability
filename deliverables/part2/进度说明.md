## 1. 研究背景与核心问题

- **化学空间**：58 个分子 = core set 18 + broad pool 40。
- **模型阶梯**（沿介质与条件态逐步加深）：
  `P0 (气相极小) → P1v (竖直) → P1a (绝热) → P2a / P2eps (溶液优化) → C0 / C1 ([LiM]⁺) / C2 ([Li(M)₂]⁺)`，共 11 个 rung。
- **核心科学问题**（R13 原话）：**「定量研究缺失物理何时真正改变材料筛选决策，以及达到可靠排序所需的最小计算信息」**。
- **双轨结论纪律**：
  - **Track A**：在 designated computational target 范围内的决策稳定性（本项目的正面结论）；
  - **Track B**：外部参考 / 实验有效性（本项目在预注册判据下**未建立**）；

- **方向口径**：`ox = IP`、`red = -EA`（均 maximise）；`sigma_ij = |d_lower - d_upper| / sqrt(0.5)`。

### 2.5 WP5 Δ-learning 与跨家族泛化（RQ4 前半，原 week32）

## 4. 全局口径与纪律（原话）

1. **Gate 状态**：`Gate 0 CLOSED；Gate 1 NOT CLOSED 且 NOT CLOSABLE（本批次只登记与复算既有冻结数据：不复核、不关闭、不跳过；排序/配对证据零新增电子结构计算、零数据剔除、零阈值改动……）`
2. **三层表述**：三层表述（模型事实 / 统计判定 / 材料意义）**不得混写**；每份报告都区分模型事实 / 统计判定 / 材料意义。
3. **轨道标签**：主结论一律带 Track A / Track B / 待验证推断标签。
4. **措辞禁令**：只用 `designated computational target` / `designated reference model`，**Gate 1 闭合前禁用 `validated target`**；`NOT CLOSABLE` 不等于 `NO SUCH DATA EXIST ANYWHERE`。
5. **方向与缺值**：`ox = IP`、`red = -EA`（均 maximise）；`sigma_ij = |d_lower - d_upper| / sqrt(0.5)`；**缺值、不合格态、未完成 QC 的状态一律记为 `None`，绝不被替换成 0**。
6. **不救 PASS**：`禁止事后通过剔除分子 / 替换模型列 / 放宽容差把它「救」成 PASS；也不再为它无限追加周次计算。`
7. **不要让外部有效性把整个项目定义成失败**：Track A 的全部结论**不依赖** Track B 是否闭合。
8. **池内饱和 ≠ 跨家族泛化**：`family-held-out 的主动学习曲线不可用；池内端点 tau_b = 1.0 是自检端点，不是成绩。`
9. **定义性结果不是经验发现**：`f_robust_inv = 0` 是定义性结果（T6a/T6b），**因此不能读成「排序稳定」**，它只是 z = 1.0 > 1/√2 的代数必然。
10. **三层判定之外还有一条工程纪律**：本镜像里的载荷是**生成物**，改动必须回代码仓库改生成脚本再重建，不手改 `outputs/**`。
