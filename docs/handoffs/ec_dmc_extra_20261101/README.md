## 梯度和频率任务如何解释

每个目标使用上一轮成功几何的原始字节，身份为 EC/LiM²⁺ +2/双重态/47 电子，DMC/LiM²⁺ +2/双重态/49 电子，DMC/M⁺ +1/双重态/47 电子。梯度每对输入只有 TightSCF/VeryTightSCF 标签不同，几何逐字节一致；其余物理方法固定 wB97X-D4/def2-TZVPD/SMD(acetonitrile)。

当前九个单点只给电子能量和波函数诊断，不能直接回答 TightSCF 下新末几何是不是合格驻点，因此追加 EnGrad。之后才决定频率对照是否值得跑：若 TightSCF 梯度不过原冻结阈值，固定几何频率仍可作为数值 Hessian 敏感性诊断，但不能把其热化学量当合格极小的自由能；若要得到该设置下的可用 G，需要另行规划严格优化，不能自动启动。

即使两套频率结果接近，也只是三个指定几何上的局部对照，不能替代全相关 cohort 的协议可比性评估。频率包不继承“梯度小所以必然可比”的判定，不设置事后挑选的容差。

## 筛选起点如何保证真实与可审查

复用项目已有 `build_torsion_probe_package.py` 的拓扑、合法桥键旋转、Li 协调候选和 `validate_candidate_start` 门，不另写一套化学验收规则：

- Li 探针：只保留沿 O 供体方向的 ±0.15、±0.30、±0.45 Å 位移候选，显式声明 `li_coordination_change`；它们不改变共价骨架，不计作环形变/骨架扭转。固定排序、每态最多六个起点；全部尝试的拒绝或截断原因保存。
- DMC/M⁺：使用已核验的两条重骨架桥键二面角 `(0,1,2,3)` 和 `(1,2,4,5)`，分别 ±60°；中心键必须为拓扑登记的单键桥，不允许 C=O 或环键旋转。
- 所有 16 个入包起点通过相同元素顺序、共价拓扑、非刚体变化、同态历史候选中可用起点及本批起点的对称等价检查；另做最小原子间距 0.75 Å 的起点碰撞预检。该距离只是起点筛查条件，不是生产态验收阈值。
- 几何门的真实分类已断言为 **12 li_coordination_change / 4 heavy_fragment_torsion**。完整已知历史起点检查路径数与每条拒绝原因保存在 CANDIDATE_PREFLIGHT.json / candidate.json；不把未登记历史文件的全空间遍历声称为已完成。

筛选采用既有 GFN2-xTB **气相**方法，仅作候选探索。每个种子最长 480 秒，失败/超时保留日志并继续本组其他已登记种子，不重试；每组最多六个种子，受一小时 Slurm 总上限约束。按组检查 `cores.txt=4`，脚本声明 `ntasks=4, cpus-per-task=1`，xTB `OMP_NUM_THREADS=4`，避免历史上核数相乘导致的漏计费。

原始起点与 `xtbopt.xyz` 分开保留。后续须检查终点的共价身份、Li 配位、去重与独立性，再按预先限定规则挑少量严格 DFT 起点。xTB 能量不报作生产自由能；一个筛选轮也不能证明搜索已穷尽。没有自动打包或提交 DFT 的后续链。
