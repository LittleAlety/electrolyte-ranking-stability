# /goal 四态恢复与后续一致性收口

## 目标及授权边界

以本轮真实科学证据争取系综 48/48 accepted，固定原有 48 分母，不修改 QC 标准。DMC 两态数值收敛恢复与 DOL/EC 环构象/配位搜索是两条不同路线。工程全绿、正常终止或限制报告均不能代替目标完成。

本文件是执行交接稿。当前前置包创建不代表计算已获自动提交权限。只有用户明确启动本轮计算后，执行者才可在绑定授权的生产清单与预算内连续推进。计划本身、文件名和 `ready` 字符串不构成授权。

方法保持 wB97X-D4/def2-TZVPD、SMD(acetonitrile)、VeryTightOpt、解析梯度、AnFreq、原热化学及身份口径。不使用 NumGrad；不为单条腿回退 NumFreq。原配置中历史流程描述若与全组 AnFreq 修订冲突，报告冲突并以已冻结正式政策及验证代码核对，不能自行重新采用旧算法。

## 顺序与阶段出口

### P0：同步状态与防误提交

- 读当前 HEAD、未提交文件、四态 labels/structures/dispositions/reviews 和实际源几何；保存基线。
- 重核 Slurm，不因旧报告称“在飞”而等待，也不因观察超时而重复提交。
- 候选、批次、尝试、Slurm 元素和成本逐级关联。取消、拒绝、被替代、规划和真实运行分开。
- 新版本候选先走通注册→导入→去重→覆盖复核的合成测试。尤其检查 `recovery_v1` 和 `tors_` 硬编码；新环/motif 成员不能因前缀不同不可见，也不能假装成扭转成员。
- 已通过的覆盖复核必须绑定证据哈希，源证据变化时失效，不能只保留旧 resolved 缓存。

出口：无重复在飞；模板不被当成生产包；新角色消费者已验证。

### P1：起点证据与合法性

- 从带键级的登记拓扑建立原子映射，不单凭元素序列相同。Li 配位与共价键图分开。
- 拒绝整体旋转/平移、等价原子换序、错误 C=O 扭转、非法断环和严重碰撞。
- 分别记录甲基转子、重骨架变化、环形变及 Li 配位变化；甲基转子不能冒充重骨架覆盖。
- 保存生成前后几何的原始字节哈希、距离不变量、对称映射证据及拒绝原因。
- 起点槽位允许少于八个有效候选；不得为了满额制造“独立”几何。

出口：每个拟算起点有真实几何、身份、独立性类别和预检证据，且进入正式候选清单。

### P2A：DMC/M_plus 与 DMC/LiM_2plus

- 先分析终点附近能量、梯度、位移、SCF 和配位变化，确认属于 TolE、步长、迭代上限、噪声或身份问题。
- 第一条可从自己的可信终点恢复优化。重启只能作为收敛补救，不能算作新独立起点。
- 第二条须有独立来源或明确不同的合法构象/配位依据。记录父尝试，不清历史计数。
- 优化坐标、初始 Hessian 或步长策略按诊断登记；新几何不能复用旧梯度/频率拼接成一条结果。
- 不允许首步收敛表缺值默认为零；五项数值和完整终点证据必须存在。
- 涉及网格/SCF 数值协议改变的诊断单列，解决可比性之前不得混入正式标签。

出口：严格 QC 通过并可复核覆盖，或带明确失效机制的有因补救申请。

### P2B：DOL/LiM_2plus 与 EC/LiM_2plus

- 没有非环 rotatable bond 不代表没有环构象或配位自由度。
- 分开生成合法环形变与 Li 供体方向，再构造组合。EC 的原 C=O 误扭转明确排除。
- 每态两组不同种子的有界搜索，每组最多 32 原始候选；目标态 charge/multiplicity 从账本核验。
- 小环构象生成与 GFN2 筛选都在 Slurm 计算节点执行；禁止调用仓库旧脚本中的本地 xtb.exe 路径。
- 先拓扑/对称/碰撞去重，再做筛选；每态最多两个生产起点。
- 6 kcal/mol 筛选窗沿用正式规则。GFN2 全部塌缩时，可使用预注册的生产级覆盖探针分支，但必须区分“探针”与“GFN2 新极小”，不能偷换筛选标签。
- 若安装环境缺少所需生成库，先核查已有计算环境；安装也经 Slurm 并计入筛选预算，禁止登录节点计算或无限安装依赖。

出口：两个合法生产起点或逐类不可生成的证据；不能提交被预检拒绝的候选凑数。

### P3：预算与调度

- 建议总上限 800 allocated core-hours：筛选 8×2核×2h=32；首轮 8×16核×4h=512；有因补救 4×16核×4h=256。
- 每态最多两个首轮生产起点、一次补救。补救沿用父起点，父任务已终止且原因明确；不伪装第三个独立起点。
- 已消耗 + 排队/运行/待提交预留共同约束预算。终态实际成本缺失时不得按零释放额度。
- 真实失败和取消前消耗都计费；一个 Slurm allocation 仅计一次，不能再把 .batch/.extern 重复相加。
- ORCA 默认 16核，%pal 与 Slurm 一致；筛选最多2核。当前 QOS 能同时提供多少核须实时核验，不假定四条16核可同时跑。
- 全账户 running+pending≤20。通过受保护命令桥 doctor 后才能用生产提交器，禁止裸 ssh/scp。
- 批次使用专属清单；数组索引→任务映射、远端输入哈希、核数/时间/内存预检齐备。
- 同一任务身份已有真实提交时不重提。观察超时不等于作业失败。

出口：授权、资源、科学输入及队列四类门都通过后，才允许生产提交。

### P4：回收与科学验收

- 逐文件回收 inp/log/xyz/hess/轨迹/stderr/时间元数据与 Slurm accounting，核对原始字节哈希。
- 证明输入→自身终点→Hessian→热化学同源；AnFreq 坐标轴变化采用已有框架不变量校验。
- 正常结束、零虚频、SCF 收敛、五项优化阈值、电子/结构身份分别检查；任何一项不能替代其他项。
- 真新极小按正式映射去重进入覆盖复核；同盆地复现只增加覆盖证据，不增加简并度。
- 单盆地放行必须满足既有覆盖协议；本包不新造“跑两次=全局充分采样”规则。
- importer→coverage→aggregator→下游重建，同步记录历史限制与新 resolution；拒绝直接编辑 accepted。
- 单个状态放行后不再为它启动无必要任务。已经在跑的其他合法任务不随意取消；评估证据需要与费用后按授权处理。

### P5：计算等待期的工程工作

- 完成三个旧缺口：私人 work 夹具依赖、合成成本未调用生产 join、formal source 接受缺列/缺组/未知状态。
- 本包 budget validator 仅是新轮次账本参考，不代表 WP5 job-query 成本已接通。
- 其他执行者已在改 acquisition v2，先交接再接管，不重写或覆盖正在做的模块。
- 保留旧回放与模型/查询器身份；新版本协议、随机种子和不确定性估计先冻结，盲性与跨进程确定性测试先通过。
- 四态标签稳定后再执行正式全量回放。即使 48/48，也要逐项检查 A/B目标、特征和成本是否支持12分子池。

### P6：收口与交付

- 重建 free/Li/shift、系综、WP3排序威胁、A/B停止预算、完整成本、3→6差异、合规、README与Pages。
- 采样独立容差未冻结时仍只报告差异；WP6满足前置不等于本轮自动获准算配体。
- 针对全部新模块做回归、只读 --check、干净环境复现和不带 -Commit 的收口链。
- 交付每态证据、起点/尝试/成本谱系、旧44/48与新结果对比、核心计划逐项状态和发布候选。
- 真正成功条件为四态按现有规则放行、全48态accepted且证据/下游一致。否则保持目标未完成，列出下一轮所需机制与预算。

## 失败预案

| 现象 | 处理 | 不允许 |
|---|---|---|
| 连接/doctor失败 | 停止远端操作，继续独立离线工作 | 绕过命令桥或索要密码 |
| 队列健康但无新输出 | 核实阶段和资源使用，按间隔观察 | 重复提交 |
| 运行超时 | 核验终止、保存证据、预算内有因续算 | 擅自扩大预算 |
| 优化阈值仍失败 | 登记具体准则和趋势，使用一次有因补救 | 改阈值/填零/无因无限重启 |
| GFN2只回旧盆地 | 登记筛选结果，按已预注册探针分支决定DFT | 宣布生产势面无新盆地 |
| 同一极小重现 | 保留独立覆盖证据，正确去重 | 多算Boltzmann简并度 |
| 漂移态 | 独立记录并拒收不合身份标签 | 改物种名塞回同态 |
| 预算耗尽仍非48/48 | 保持未完成并申请明确下一轮 | 把限制报告当完成证书 |

## 状态更新与持续执行

使用产品提供的监控机制跨会话跟进；无变化且健康时安静，完成/失败/需要动作时通知。程序待算阶段继续完成独立工程工作。每个阶段记录完成证据和下次恢复入口，不按固定小时数承诺完成。
