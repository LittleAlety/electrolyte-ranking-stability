# 归档依赖声明（链内 `work/` 读取清单）

`work/` 是 **gitignored** 的机器本地层——clean clone 完全没有它。本文件把链内
**每一个读取 `work/` 的脚本**、它读什么、为什么读、**证据来自哪个归档**、以及
**缺失时的行为**逐条声明，以落实第 12 项「**依赖必须显式，缺失不能被静默跳过**」。

> 守卫：`tests/test_archive_dependency_inventory.py` 会**重新推导**链内引用 `work/` 的
> 脚本集合，并要求与本清单**逐项一致**——新增依赖若不登记，测试即红。

## 已落地的响亮拒绝（此前为静默降级）

| 位置 | 原行为 | 现行为 |
|---|---|---|
| `build_ensemble_cost_by_family` | 成本账 **0 行**，静默 | `SystemExit`：空账是**跳过声明的依赖**，不是零成本 |
| `build_coverage_reviews` | 排除集 **空**，静默（会重新放行已取消元素） | `SystemExit`：不得**静默重新放行**被拒/被取消成员 |
| `build_recovery_budget_accounting` | 打印 **「0.0/600 core-hours」**（真实 187.0） | `SystemExit`：报 0.0 等于**声称什么都没花**，这是假的 |

## 尚未声明来源的部分（如实列出）
