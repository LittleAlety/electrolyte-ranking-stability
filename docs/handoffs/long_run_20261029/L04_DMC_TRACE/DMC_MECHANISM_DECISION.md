## 1. 解析契约（避免把表当次数）

- 按实际表头识别 `Item / value / Tolerance / Converged` 的**竖排**几何收敛表（不是 SCF 表）；每个表 = 一个优化 cycle。
- 一个日志里可含多个优化段（如 reopt 从末几何重启）；`cycle/of_cycles` 是**该段内**编号。
- 能量取表前最近的 `Current Energy .... <E> Eh`；TolE 用绝对值。
- `primary` 两行是单点/频率任务（无几何优化表）⇒ `cycles=0` 如实记，不拿它当"优化失败"。
- `tors_7_0_1_2 | pending` 无 `log_path` ⇒ `MISSING` + 原因，不补值。
- **（更正）** 三条 M_plus 探针日志哈希不同，是三次独立**运行**；但它们共享同一**输入几何**，
  末值逐位相同是「同一输入重复运行」的预期结果，不是独立起点检验。

## 3. 机制候选（唯一 ID；逐条回答五问）

### `OPT-COORD-1`（原 B：优化器坐标/信赖域；**保留推荐**）
- **改变什么**：只改 ORCA 几何优化的坐标/信赖域控制（Redundant Internals → Cartesian，或 trust radius 初值），**不改电子结构、介质、阈值、方法关键字**。
- **为何针对失败**：M_plus 的步长受限形态（梯度已低、唯 MAXD 1.62×）与坐标/步长控制直接相关。
- **如何否定**：≤30 周期内 MAXD 步仍 >2× 而梯度/RMS 步已过 ⇒ 否定（说明是平坦谷而非坐标问题）。
- **所需对照**：与既有 24 周期 verytight attempt 逐项对比末 cycle 五准则；几何去重用生产原语。
- **证据强度（更正后）**：M_plus 的 4 条同型腿只对应 **1 个独立输入坐标**（三份重复 + realfragment 一个不同起点），
  故「优化器在低梯度处停住」这一形态有 1 个独立起点 × 多次重复；**不能**说「已穷尽起点侧」。
- **可比性**：按 §6.2，改优化算法不自动要求全 cohort 重算，但须版本化并记录「仅 DMC 两态使用该设定」；阈值与验收不变。

### `LI-SHELL-1`（原 A：显式 Li 配位；**只适用 LiM_2plus，首轮不推荐**）
- **改变什么**：首段把 Li–O/N 壳约束或显式配位处理，再放开。
- **为何针对失败**：LiM_2plus 的发散型失败与 Li 壳重排**形状一致**（假设）。
- **如何否定**：放开后 ≤10 周期内 MAXD 仍 >2× 且最终几何与已登记极小 RMSD <0.35 Å ⇒ 无益。
- **所需对照**：同一原始输入、同一 profile、同一阈值；对照＝不做 Li 约束的既有 attempt。
- **红线**：M_plus 无 Li，禁止套用；约束段产物不得直接当最终几何交 QC。
- **证据强度（更正后）**：LiM_2plus 的 `tors_6/8` 是同一输入重复，只有 `tors_7` 的 v1 与 reopt_v3 是不同输入；
  故 Li 壳假设**缺少真正的独立起点对照**，首轮不推荐。

### `START-GEN-1`（新增：修复探针生成并检验真正独立的起点；**作为前置推荐**）
- **改变什么**：先修生成/校验链，使不同 dihedral 真正落到不同坐标（按结果坐标去重，而不是按标签/SHA），
  再构造 2 个**坐标不同**的起点；不重跑历史作业、不改历史输入。
- **为何针对失败**：更正后的核心事实是「起点侧从未被真正检验」；`OPT-COORD-1` 只针对优化器，不解决起点问题。
- **如何否定**：若新起点与既有起点坐标不同、仍收敛到同一极小且五准则不过 ⇒ 才可支持「起点侧已尽」。
- **所需对照**：新起点 vs 已登记极小（生产去重原语）＋同一 profile 的既有 attempt。
- **成本**：生成与校验为**本地零成本**；若后续要跑新起点，属**新计算**，须另行授权（本任务不启动）。

### `PREOPT-GFN2-1`（原 C：GFN2 更紧预优化/换泛函级别；**不推荐**）
- GFN2 更紧预优化不保证 DFT 阈值改善；换泛函属方法变更，超本轮范围。
- 注意：旧草案里的「B」指 GFN2 预优化，与本文件的 `OPT-COORD-1` **不是同一件事**；今后只用唯一 ID。

## 4. 结论（更正后）

1. **先做 `START-GEN-1` 的本地修复与反例测试**（零新计算）：当前生成器已能拒绝相同坐标的第二起点（实测 `rigid_transformation`），
   但历史上一次生成留下了重复坐标；修复点在于「按结果坐标去重 + 拒绝同轴同片段重复」，并保留历史包为审计副本。
2. **`OPT-COORD-1` 保留为可选机制**，但引用时必须写明其证据只来自 1 个独立 M_plus 输入 + 重复运行；
   **不得**用它支撑「起点已尽」。
3. **`LI-SHELL-1` 与 `PREOPT-GFN2-1` 首轮不推荐**。
4. **DMC 本轮停止的裁决未变**：本文件只是呈报；任何新计算（含 `OPT-COORD-1` 或新起点腿）都须另行授权。
