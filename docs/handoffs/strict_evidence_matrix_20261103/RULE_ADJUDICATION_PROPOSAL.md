## C. 批准后的唯一执行单

1. 记录 F1–F6、P1、C1–C7 的批准或修订文字、适用版本和输入哈希。**P1 不能隐含批准**；若尚未决定，重建输出明确列 `PRIMARY_RULE_PENDING`，不得报告严格 48/48。
2. D7/D8 独立复审通过后，由唯一生产写入者受控切换并显式迁移接收账本；真实入口做 pending/failed 阻断和通过样例。历史尝试、失败及费用保持原样。
3. 在隔离输出目录对 48 态逐成员执行：**证据接收 → 身份与协议资格 → 严格成员资格 → 合格候选登记 → 共同去重 → coverage → 聚合**。资格判断覆盖旧 `kept=true/false` 的全部相关成员；不合格成员只留历史/失败账，不进入重建池。独立审计者核对输入哈希、逐态原因和费用差异。正式文件只有复审通过后才切换。
4. 输出四类互斥动作清单：`现有材料充分`、`现有文件可补齐`、`仍需点名条款裁定`、`确需新物理证据`。最后一类逐条写目标成员/关闭的门、最小实验、预算上限、停止条件；**不从 31 态或五条暂存数直接推算作业数**。
5. 成员准入重建完成后，另按预批准 δ/区间规则重跑 WP3/WP5/适用 WP6 的研究结论门；成员 accepted 数与排序稳定性分别报告。可复现发布与终审单列。
