- `accepted` 是历史协议标签；严格五项门与跨协议可比性未批准，因此本表不产生严格 accepted 数。
- 首点情形 A/B 仅沿用已有双路径模拟，不能当正式结论；`primary` 缺能量字段须另行核验。
- DMC 接收候选来自暂存登记，`staged` 不进入聚合；EC 新候选仍须末态身份、旧 p4/p7 登记及共同去重审查。
- 先裁定规则并全量隔离重建；计算需求只在逐成员零计算检索后确认。
