# Week 22（W22-H）计划 —— 论文加固与统一数据

- 背景：外部专家对结题论文 PDF（`论文/电解液溶剂氧化还原描述符决策稳定性_结题论文.pdf`）逐页审查，给出 A1–A6 硬伤、B1–B5 统计与证据链、C1–C8 文字规范、D1–D7 科学深化四组意见。
- 命名说明：仓库已有 `week22`（Stage 23），本周次为**论文加固周**，落盘命名空间统一为 `week22_hardening`/W22-H，避免覆盖既有产物。
- 唯一变量纪律不变：本周**不新增任何电子结构计算**，只做（i）论文文本与数值口径修订、（ii）统计证据加固、（iii）数据统一归档。

## 1. 目标

1. 把 A1–A6 的硬伤在论文源（`论文/build_paper_docx.py`）中修掉，并重建 docx/PDF。
2. 为 B1（ρ 的置信区间与敏感性）、B2（Δτ_b 配对 bootstrap）、B3（多重比较）、B5（broad pool 敏感性）补上可复算证据。
3. 把 B4/C/D 中已有产物（前瞻检验、Gate 1 within-series、热修正、NEB、配位饱和）写进论文正文。
4. 产出**一个统一数据文档**，把 week1–week23 的全部关键数字与来源路径汇总。

## 3. 判据与纪律

- 所有新增统计量给出**口径、随机种子、bootstrap 次数**；不引入新计算。
- 论文中「定理（严格界）」与「实测（零漏）」必须分开写：严格界用 2·A_axis，靶向节约是经验结果。
- 非注册项（missed-solution allowance）一律按非注册项引用，不写入 prereg 冻结量。
- 论文数字必须能追溯到 `outputs/` 下的具体产物路径。

## 4. 风险

- 论文 docx 被 Word 占用 → 采用 `PAPER_OUT` 环境变量重建到 `_v2` 副本，非破坏性。
- broad pool 闭式判据缺 P1/P2 层 → 预测只作**排序级演示**，不外推绝对值。
- n=10 的 ρ 与 n=12 的 Δτ_b 置信区间均偏宽 → 论文按「方向性证据」而非「显著差」表述。
