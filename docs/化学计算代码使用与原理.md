# 化学计算代码使用与原理

> 阅读对象：希望理解本仓库如何从分子结构得到氧化/还原代理量、如何比较排序、以及如何复核计算结果的读者。依据当前工作区代码与产物整理，检查日期：2026-11-05。`outputs/` 和 `work/` 仍可能变化；具体进度请以当时的机器可读账本为准。

## 1. 项目究竟计算什么

本项目研究的是**候选溶剂排序决策的稳定性**：便宜的电子结构代理量、几何弛豫、连续介质、Li⁺ 配位、构象系综等处理逐层加入后，候选的相对顺序与 Top-k 选择怎样变化，以及这些变化能否超过方法和采样的不确定性。它不提供普适的“最佳电解液溶剂排行榜”，也不把一电子氧化/还原热力学差直接等同于实际电池中的分解电位或寿命。总体定位见[项目首页](../README.md)、[冻结科学定义](../config/scientific_definitions.yaml)和[当前批次协议](physics_completion_protocol.md)。

仓库有两条相关但不同的计算线：

| 计算线 | 样本和目标 | 主要代码 | 主要产物 |
| --- | --- | --- | --- |
| 历史 P0/P1/P2、C0/C1/C2 阶梯 | 18 个 core 分子、40 个 broad pool 候选；比较便宜代理量、气相单点、弛豫、连续介质、Li 配位和显式第一配位壳 | `scripts/run_*.py`、`scripts/analyze_*.py`、`src/electrolyte_ranking/` | `outputs/week*/`、`outputs/decision_state/` 等 |
| 当前 `physics_completion_v1`（WP0–WP6） | 12 个主集分子 × 4 个主态，重点是氧化自由能、系综、方法审计与决策成本 | `scripts/production/`（六分类；旧路径 `scripts/wp_production/` 是转发入口） | `outputs/physics_completion/` |

历史阶段的 `weekNN` 是**工作轮次编号**，不是日历周。当前代码和权威产物的目录关系见[仓库地图](65_repo_layout.md)；脚本入口见[脚本索引](../scripts/README.md)与[生产脚本说明](../scripts/production/README.md)。

## 2. 从化学结构到结果的数据流

```text
分子清单/SMILES 与预注册定义
  → 3D 起点、构象搜索、Li 配位 motif 候选
  → GFN2-xTB / CREST 低成本筛选与去重
  → ORCA 单点、几何优化、频率与热化学
  → 日志解析 + 收敛/虚频/结构身份 QC + 来源哈希
  → 每个化学态的合格构象系综自由能
  → 氧化/还原差值、Li 配位响应、方法敏感性
  → pair、Top-k、regret、不确定性与成本分析
```

输入定义在 `config/`；分子及实验锚点在 `data/`；初始或归档几何在 `structures/`；可复用计算和排序函数在 `src/electrolyte_ranking/`；批次驱动与报告生成器在 `scripts/`；可审计的派生结果在 `outputs/`。`work/` 是本机原始日志和临时计算层，通常不随 Git 克隆取得。因此，干净克隆可复核已提交的派生证据，但需要原始日志的构建器可能明确拒绝运行。

## 3. 主要物理量与符号

以中性分子 `M` 为例，`E` 表示电子能，`G` 表示在指定模型和标准态下的 Gibbs 自由能。同一对状态必须使用可比的计算设定；项目内部能量常以 Hartree 存储，比较量转成 eV（1 Eh ≈ 27.211386 eV）。

| 量 | 项目中的表达式 | 作用与判读 |
| --- | --- | --- |
| `P0_ox` | `−ε_HOMO(M)` | 极便宜的单一标量代理量，数值大按项目约定更抗氧化；不是氧化电位 |
| `P1v` / `Eox_vertical` | `E(M⁺; G1) − E(M; G1)` | 两态用同一几何 `G1` 单点，考察垂直氧化；不包含各态弛豫 |
| `P1a` / `Eox_adiabatic` | `E(M⁺; relaxed) − E(M; relaxed)` | 中性与阳离子分别优化，分离几何弛豫的影响 |
| `P2a` | `G_SMD(M⁺) − G_SMD(M)` | 固定乙腈 SMD 背景下的自由能差；所有候选使用同一背景 |
| `P2eps` | `ΔG(ε)` | 裸 CPCM 的介电常数扫描，仅考察静电屏蔽敏感性；不与 SMD 混成一条“换溶剂”曲线 |
| `Gox_ensemble` | `Gens(M⁺) − Gens(M)` | 各电荷态先独立建立构象系综，再作差；当前主目标之一 |
| `Gox_Li_ensemble` | `Gens([LiM]²⁺) − Gens([LiM]⁺)` | Li⁺ 配位条件下的氧化代理量 |
| `coordination_shift` | `Gox_Li_ensemble − Gox_ensemble` | Li 配位相对自由分子的条件响应；不同物种，不应误作单纯方法升级 |
| `Sred` | `G(reduced) − G(parent) = −EA` | 统一的抗还原评分；`Sred` 取最大与原始 `EA` 取最小应选出同一集合 |

主氧化轴的选择方向是 **maximize**。气相阴离子若不束缚，或还原后电子身份不属于 `molecule_centered_redox`，对应还原数值不能硬塞入主排序。缺失值使用 `None`，不能当成 0。上述量的精确定义和限定条件以[科学定义](../config/scientific_definitions.yaml)与[批次配置](../config/physics_completion_v1.yaml)为准。

### 构象系综的计算

对同一电荷态、同一化学计量、同一模型内的合格极小值 `i`，自由能为：

```text
Gens = −RT ln Σᵢ gᵢ exp(−Gᵢ/RT)
     = Gmin − RT ln Σᵢ gᵢ exp[−(Gᵢ − Gmin)/RT]
```

第二式是代码采用的稳定形式，避免直接对很大的负能量取指数。`gᵢ` 是**事先登记**的简并度，未登记时为 1；各成员的 Boltzmann 权重归一后总和为 1。这里的 `Gens` 不等于按权重求出的 `ΣwᵢGᵢ`。不同电荷态分别求系综，再作氧化差值，不要求逐个构象一一配对。生产聚合实现见 [`build_production_ensemble_aggregator.py`](../scripts/production/ensembles/build_production_ensemble_aggregator.py)；GFN2-xTB 的筛选级系综见 [`build_wp2_ensemble_free_energies.py`](../scripts/production/ensembles/build_wp2_ensemble_free_energies.py)，后者**不能替代**生产级 DFT/SMD 自由能。

## 4. 电子结构方法和代码的对应关系

1. **便宜筛选。** `scripts/run_xtb_job.py`、`scripts/run_broad_pool_p0.py` 与生产目录的 `run_batch.py` 使用 GFN2-xTB 生成或筛选几何、轨道代理量及 Li motif。历史构象方案登记了 CREST/GFN2-xTB 搜索、能量窗口和几何聚类；并非每个历史脚本都完整执行当前生产协议。
2. **历史单点与连续介质。** `scripts/run_core_set_p1.py` 在共享 GFN2-xTB 几何上做中性/阳离子/阴离子 ORCA 单点，属于 `P1v`。`scripts/run_p1a_adiabatic.py` 处理弛豫差值。`scripts/run_core_set_p2.py` 用 `--solvent` 选择 SMD 溶剂，或用 `--epsilon` 选择裸 CPCM 介电扫描。两种环境实验必须分开解释。
3. **当前生产腿。** 冻结主态是 `M`、`M_plus`、`LiM_plus`、`LiM_2plus`，12×4=48 个态；另有中性 `M_tzvpd` 腿用于与带电态基组一致的比较，因此队列可见 12×5=60 条腿。`run_wp2_production.py`、`run_wp2_extra.py` 和 `run_wp2_queue.py` 负责历史批次的计算与调度。生产方法的核心是 `wB97X-D4`、`def2-TZVP/TZVPD`、固定 `SMD(acetonitrile)`；带电腿使用含弥散函数的 `TZVPD`。几何起点优先为 r2SCAN-3c，回退到 GFN2-xTB 时必须在账本中标明。
4. **导数与频率政策。** 早期 `run_wp2_production.py` 源码仍可见 `Opt NumFreq`，这是历史执行入口，**不能据此推断当前频率政策**。当前冻结协议 v1.3 对全 cohort 采用解析梯度优化、`VeryTightOpt`，并把频率 Hessian 统一改为 `AnFreq`；`NumGrad` 禁止。原因和 60/60 配对审计见[协议 §4](physics_completion_protocol.md)与[配对审计](../outputs/physics_completion/method_audit/anfreq_paired_audit.md)。新任务输入还经过 `orca_derivative_policy.py` 校验。旧 `TightOpt` 结果仅在零虚频和其他 QC 通过时保留。
5. **热化学与身份。** ORCA 日志中的电子能、最终 Gibbs 自由能、热校正、频率和收敛状态被解析到逐腿记录。导入器核对几何、日志、频率、热化学与来源；结构断裂、配位变化、自旋/前沿轨道身份等需要单独审查。几何优化得到断键产物，不自动证明实际溶液里存在快速反应路径。

SMD 乙腈、298.15 K 和 1 mol/L 是**统一对照条件**，不是每个候选各自纯液体或真实盐配方。结果应称为“指定计算目标”，不称为已经实验验证的目标；外部 Gate 1 的排序一致性没有闭合。

## 5. 质量控制、去重与验收

一个任务“程序正常退出”或“算出数值”，不等于该态可用于正式排序。主要检查依次包括：

| 层级 | 检查内容 | 相关实现/证据 |
| --- | --- | --- |
| 作业与来源 | 输入、程序版本、路径、哈希、运行状态；防止旧结果或混用梯度 | `src/electrolyte_ranking/orca.py`、`qc.py`、`provenance.py`；`scripts/production/ingest/import_hpc_opt_numfreq.py` |
| 几何和频率 | 优化收敛、五项 `VeryTightOpt` 阈值、完整 Hessian、显著虚频；失败尝试也保留记录 | `scripts/production/ingest/import_ensemble_structures.py`、`orca_derivative_policy.py` |
| 状态身份 | 化学计量、连接关系、Li 供体、氧化/还原中心及轨道身份；漂移不得当原物种 | `scripts/production/validation/build_state_identity_qc.py`、`frontier_fmopop.py`、`frontier_spin_qc.py` |
| 同态去重 | 原子映射与键图、重原子 Kabsch RMSD（0.35 Å）、扭转角（10°）、Li 供体与手性等 | `scripts/production/ensembles/build_production_ensemble_aggregator.py` |
| 采样覆盖 | 已登记候选是否逐个结案；单盆地覆盖要有可核验的独立复现 | `scripts/production/ensembles/build_coverage_reviews.py`、系综 `dispositions` 与 `labels` |

系综标签把三件事分开：`numerical_status` 表示是否有数值，`sampling_status` 表示登记搜索是否结案，`acceptance_status` 表示能否正式使用。待处理候选使结果为 `provisional`；没有解决的采样限制为 `limited`；只有相应证据齐备才为 `accepted`。当前工作区的 `production_ensemble_labels.csv` 有 **45 accepted、1 provisional、2 limited**；未 accepted 的是 `DMC/M_plus`、`DMC/LiM_2plus`、`EC/LiM_2plus`。这只是 2026-11-05 的工作区快照；根 README 与旧导航页可能保留不同时间的数字。严格完成判定还要检查成员身份、采样、WP3、WP5、成本及条件触发的 WP6，不能只看 48 个标签是否有值。

## 6. 排序稳定性与不确定性怎样算

对候选 `i,j`，先取同一指标下的差值 `ΔPᵢⱼ = Pᵢ − Pⱼ`。项目用 `|ΔPᵢⱼ| ≥ max(zσᵢⱼ, δ)` 判定该模型是否能分辨该 pair；其中 `σ` 是事先规定的不确定度、`z` 是门槛倍数、`δ` 是预注册的实用容差。跨两个模型比较时：

- 两模型都能分辨且方向相同 → `STABLE`。
- 任一模型不能分辨 → `UNRESOLVED`。
- 两模型都能分辨且方向相反 → `ROBUST_INVERSION`。

代码在 [`ranking.py`](../src/electrolyte_ranking/ranking.py)、[`decision_state.py`](../src/electrolyte_ranking/decision_state.py)；还计算 Kendall `τ_b`、Spearman `ρ`、Top-k overlap/Jaccard、selection regret、阈值决策误差。对主分析使用的**双模型本身构造的** `σᵢⱼ = |ΔPᵢⱼᴬ − ΔPᵢⱼᴮ|/√2`，[`robustness.py`](../src/electrolyte_ranking/robustness.py)证明当 `z > 1/√2` 时稳健反转在代数上不可能。因此历史结果的“0 个 robust inversion”**不是排序稳定的独立证据**；应同时看 `UNRESOLVED` 比例、`z` 敏感性，以及独立方法/采样证据。

WP5 的 Δ-learning 用廉价量预测“目标量 − 廉价量”的位移，再与直接预测作对照；盲回放按候选逐轮保存预测与可见标签，评价真实 Top-3 的重合度和平均 regret。停止预算要求相邻两个**非耗尽**预算点、同一批重复实验都达到预注册门槛；池耗尽后的平凡全知结果不能充当节省成本的证据。模型与规则见 `src/electrolyte_ranking/wp5.py`、`scripts/production/analysis/wp5_formal_models.py`、`wp5_replay_contract.py`。

以下命令从仓库根目录执行。Windows PowerShell 示例中的 `.venv\Scripts\python.exe` 可以换为已经安装项目依赖的 `python`。基础包可按 `python -m pip install -e ".[science,dev]"` 安装；**ORCA、xTB、CREST 不由 `pyproject.toml` 安装**，实际计算还需要各程序、许可证或集群环境及正确的路径配置。

## 8. 常见误读与阅读顺序

1. **“算完”不等于“验收”。** 同时检查运行状态、QC、状态身份、采样覆盖和 `acceptance_status`。
2. **筛选自由能不等于生产自由能。** GFN2 气相系综只能说明低成本模型上的趋势，不能替代 `wB97X-D4/SMD` 目标。
3. **0 次稳健反转不等于稳定。** 双模型 σ 的构造使某些门槛下反转在数学上不可见；大量 pair 仍不可判定。
4. **SMD 与裸 CPCM 不能混读。** 固定乙腈背景和只改介电常数回答不同问题。
5. **Li 配位态与自由态是不同物种。** `coordination_shift` 是条件响应；还原中心变为 Li 或结构漂移时不能继续当作同一种分子还原排序。
6. **旧脚本与新协议的关键词可能不同。** 对当前科学口径，先读冻结配置、协议修订和实际输入/账本，再看旧版驱动。

建议的最短阅读路线：先读本文第 1–3 节 → [当前科学协议](physics_completion_protocol.md) → [`run_wp2_production.py`](../scripts/production/jobs/run_wp2_production.py) 与 [`orca.py`](../src/electrolyte_ranking/orca.py) → [生产系综聚合器](../scripts/production/ensembles/build_production_ensemble_aggregator.py) → [排序函数](../src/electrolyte_ranking/ranking.py) → `outputs/physics_completion/` 对应账本和报告。
