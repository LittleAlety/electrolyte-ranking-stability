## 0. 一句话结论

从 Week 4 起被当作「经验不确定性」使用的 `sigma_ij`，其实有**闭式解**：它等于逐分子层间位移之差的
`1/sqrt(2)` 倍（T1），其逐对 RMS 恰等于该位移的**样本标准差**（T2），并且对层间刚性偏移**严格不变**（T3）。
由此整个 resolved / unresolved 机器可以化简为**一条无量纲判据**（T4）：

```
pair (i,j) 可分辨  <=>  q_ij <= sqrt(2)/z ,   q_ij = abs(delta_i - delta_j) / abs(P_i - P_j)
```

`q_ij` 是**方法位移相对目标轴的割线斜率**，临界值 `sqrt(2)/z = 1.414`（z = 1）或 `0.722`（z = 1.96）。
这把 Week 9 的相关系数 `rho(shift_std, tau_b) = −0.851` 升级为机制，并解释了那个一直说不通的反例：
`P0->P1 / 还原` 的位移散布全篇最大（2.25 eV），但它的位移**几乎平行于目标轴**，所以
`f_unresolved = 0.733`（分辨率崩了）而排序与候选清单**毫发无伤**（`tau_b = +0.600`，top-20% overlap = 1.00）。

## 3. 四条恒等式（T1–T4）与一条分解（T5）

这一节的全部内容是**代数恒等式（identity）**。这一点必须写在最前面，因为它决定了这些公式的**价值在哪里**：

- 下面每条 T 都是**由定义化简**得到的恒等式，所以「与实测误差 0.00e+00」**不是精度证据**，
  也不该被读成「模型拟合得好」。把它写成预测精度，等于循环论证（`docs/31` R3 的第一条动作）。
- 恒等式的真正价值是**可外推**：正因为它是代数而不是拟合，它才能在**没算过的分子、没算过的台阶**上先行使用。
  一个拟合出来的经验关系做不到这一点。
- 因此本阶段给出的不是「一个拟合得更好的代理」，而是**一条可以在花钱之前使用的判据**。
  它的样本外表现被单独检验，见 §7.4（Week 21 追加的前瞻检验）。

下面每条都在 10 个 points、45 个 pair 上做了**数值复核**（复核 ≠ 验证精度）。

### 3.1 T1 —— σ 是位移的"差"，不是位移的"大"

**命题**：`sigma_ij = abs(delta_i - delta_j) / sqrt(2)`。

**证明**：`quantify_method_sigma` 把每个实现对**逐对差值**算出来（`diffs[r,i,j] = P^(r)_i - P^(r)_j`），
再沿实现轴取 `ddof=1` 的标准差。两个观测值的样本标准差恒为 `abs(x0 - x1)/sqrt(2)`；
而 `(P0_i - P0_j) - (P1_i - P1_j) = delta_i - delta_j`，代入即得。

**数值验证**：`max abs err = 1.11e-15 eV`（machine precision）。

**含义**：`sigma` 里**完全不含**位移的量级信息。把某个方法整体平移，`sigma` 一动不动（见 T3）；
把位移的*异质性*放大，`sigma` 才跟着变。这一句话就解释了下面的全部结构。

### 3.2 T2 —— 整张 σ 矩阵压缩成一个数

**命题**：`RMS_{i<j} sigma_ij = stdev_sample(delta)`。

**证明**：用恒等式 `sum_{i<j} (delta_i - delta_j)^2 = n * sum_i (delta_i - deltabar)^2`，
再把 T1 的 `1/sqrt(2)` 平方代入：`sum_{i<j} sigma_ij^2 = (n/2) * sum_i (delta_i - deltabar)^2`。
两边除以 `C(n,2) = n(n-1)/2` 得 `mean sigma_ij^2 = sum(delta_i - deltabar)^2/(n-1) = s_delta^2`。

**数值验证**：`max rel err = 2.7e-16`。

**含义**：逐台阶看，`RMS sigma` 一列与 `sd(delta)` 一列**逐行相等**（§4 表格）。
换句话说，Week 4–9 里"σ 矩阵"承载的全部信息量，就是**逐分子方法位移的离散度**这一个标量。
这也是 3.1 的直接推论：σ 是"位移之差的散布"，它的 RMS 自然等于"位移本身的散布"。

### 3.3 T3 —— 均匀方法偏差是零成本的

**命题**：层间刚性偏移 `delta -> delta + c`（等价于 `P1 -> P1 + c`）不改变 `sigma`、`tau_b`、
`f_unresolved`、`f_robust_inv`。

**证明**：`sigma` 由逐对差值构造，公共常数在差值中相消；`tau_b` 是秩统计量，平移不改秩；
`resolved_mask` 只经 `sigma` 与 `DeltaP` 进入，二者都不变。

**数值验证**：`c ∈ {−2, −1, −0.5, +0.5, +1, +2} eV`，`max abs(d sigma) = 8.9e-16 eV`，
`d tau_b = d f_unresolved = 0`（**精确 0**，不是"很小"）。

**含义（本阶段"优化"的核心）**：一个方法可以有 2 eV 的系统性偏差而**完全无害**。
`H_var` 收费的对象只有"不均匀"。把这条写成对外结论可以省掉一整类无意义的争论
（"和方法差 1 eV 不能用"是错误的说法；正确的是"方法的*位移*沿目标轴的斜率超过阈值才不能用"，§9）。

### 3.4 T4 —— 分辨率判据（本阶段主结果）

**命题**：对第二层（P1），

```
f_unresolved(z) = Pr_{i<j}( q_ij > sqrt(2)/z )
```

**证明**：`pair (i,j)` 未分辨，当且仅当 `abs(DeltaP_ij) < z*sigma_ij` 或 `DeltaP_ij = 0`。
代入 T1 与 `sigma` 的定义，前者变为 `abs(DeltaP_ij) < z*abs(delta_i - delta_j)/sqrt(2)`，
两边同除 `abs(DeltaP_ij)` 得 `q_ij > sqrt(2)/z`。∎

**数值复核**：z = 1 与 z = 1.96 各 10 个点，**最大绝对误差 0.00e+00**。
这个 0 是**恒等式应有的结果**——`f_unresolved` 的定义与 `q_ij` 的定义只差一次代数变形，
所以它为 0 **不构成**对判据的检验。对判据的检验见 §7.4。

**临界斜率**：`sqrt(2)/1 = 1.4142`（z = 1）、`sqrt(2)/1.96 = 0.7215`（z = 1.96）。

**含义（三条，按重要性）**：

1. **判据是无量纲的。** `q_ij` 是位移对目标轴的**割线斜率**，单位相消。
   分辨率与任何能量量级无关 —— 只与"位移跑得比目标轴快多少"有关。
2. **正方形解释 Week 9 反例。** `P0->P1 / 还原` 的 `delta` 很大（sd = 2.25 eV），
   但它的 `b = +2.028`（正值、且大）意味着位移**顺着**目标轴走，割线斜率被"轴自身的间距"摊薄；
   只有那些轴间距极小的近简并对才越界。于是 `f_unresolved = 0.733` 却 `tau_b = +0.600`。
3. **"不可判定"与"排序被破坏"是两件事。** 前者由 `q > sqrt(2)/z` 计数，后者由秩相关度量。
   同一个 `delta` 可以只触发前者（§6.4 给出极端例子：`tau_b = +1.000` 与 `f_unresolved = 0.000` 同时成立，
   而 sigma 可以很大）。

### 3.5 T5 —— σ² 预算的精确分解

**命题**：对 `delta` 关于目标层 `P1` 做含截距的 OLS，`delta = a + b*P1 + r`，则

```
var(delta) = b^2 * var(P1) + var(r)           （精确，由 OLS 正交性）
```

**数值验证**：两份额之和与 1 的偏差 `max = 1.8e-15`。

**含义**：`sigma^2` 预算（由 T2 等于 `var(delta)`）精确拆成两部分：

- **平行份额** `b^2 var(P1)/var(delta)`：位移与目标轴平行，**保序**；
- **残差份额** `var(r)/var(delta)`：位移与目标轴正交，**破序**。

**但注意（这是本报告最重要的一条反直觉结论）**：**平行份额大不等于安全**。
当 `b` 是**强负值**时，平行份额同样很大 —— 而强负斜率恰恰是最危险的（§5、§7）。
所以这个分解本身还不足以给出结论，必须与 `b` 的**符号**一起读。

## 5. 相图：线性位移下的一切都是闭式

把 §4 的经验观察变成定理，只需构造一个**精确线性**的位移：
`delta = b * (P1 - mean(P1))`，即 `before = P1 + delta`。此时

```
before = mean(P1) + (1 + b) * (P1 - mean(P1))
```

于是两件事在闭式上成立：

- **排序**：`before` 是 `P1` 的**增**函数当且仅当 `1 + b > 0`（即 `b > −1`），
  是**减**函数当 `b < −1`。故 `tau_b = sign(1 + b)`。
- **分辨率**：`DeltaP_ij` 与 `Delta(delta)_ij` 严格成比例，故**每个** `q_ij` 恒等于 `abs(b)`；
  由 T4，`f_unresolved(z) = 1` 当且仅当 `abs(b) > sqrt(2)/z`。

数值验证：`max abs(q_median - abs(b)) = 4.4e-16`，`q_spread <= 3.4e-14`（即"恒等于"是精确的）。

### 6.2 拉伸目标轴 after -> mean + lambda * (after - mean)

这是本阶段唯一一个**效果有精确闭式预测**的反事实操作。被移动的一层是原层的增仿射像，于是：

- **所有秩统计量不变**：`tau_b` 与 top-k 集合逐点相同（数值上 `d tau_b` 精确为 0）。
- 记 `t_ij = Delta(delta)_ij / DeltaP_ij` 为位移的**带符号**割线斜率。移动层的逐对差值放大 `lambda` 倍，
  而位移差值变为 `Delta(delta)_ij + (1 - lambda) * DeltaP_ij`，于是

```
q'_ij = abs( t_ij + 1 - lambda ) / lambda          （对全部 pair 精确）
```

在"位移最响"的台阶（`P0->P1 / 还原`）上：

| 0.75 | 0.00e+00 | +0.600 | 2.349 | 4.494 | 4.494 | 0.778 | 0.778 | 0.778 |
| 1.00 | 0.00e+00 | +0.600 | 2.253 | 3.150 | 3.150 | 0.733 | 0.733 | 0.733 |
| 1.50 | 0.00e+00 | +0.600 | 2.086 | 1.777 | 1.777 | 0.667 | 0.667 | 0.667 |

| 3.00 | 0.00e+00 | +0.600 | 1.843 | 0.997 | 0.997 | 0.311 | 0.311 | 0.311 |

在"最安静"的台阶（`G1->G2 / 氧化`）上同样逐点吻合，只是 `f_unresolved` 从 0.067（lambda = 0.5）

**读出四条**：

1. **拉宽目标轴可以在完全不改进方法的前提下买回分辨率。**
   `lambda = 5` 时最响台阶的 `f_unresolved` 从 0.733 降到 0.244，而 `tau_b` 一个字都没变。
2. **两条渐近是闭式的**：`lambda -> 0` 时 `q' -> 无穷`（压缩轴会摧毁分辨率）；
   `lambda -> 无穷` 时 `q' -> 1`，于是 z = 1 下**全部可分辨**（1 < 1.414）、
   z = 1.96 下**全部不可分辨**（1 > 0.722）。轴的宽度与置信水平是同一枚硬币的两面。
3. **这是 Week 9 §10 读法纪律的机制依据。** `f_robust_inv = 0` 之所以不能单独读，
   正是因为"只动分母、不动排序"的操作存在 —— 本节的拉伸就是这类操作的显式构造。
4. **实践含义（可直接用）**：如果某个台阶的 `tau_b` 尚可（排序没坏）而 `f_unresolved` 很高，
   不必先怀疑方法；先看该台阶的目标轴是否**过于压缩**（例如同族分子聚集、`DeltaP` 的最小间距太小）。
   在候选池里加入若干"轴端"分子即可恢复分辨率，成本为零。

| 0.20 | +0.566 ± 0.079 | -0.034 | 0.719 | P0->P1 还原 |

### 6.4 单调且 Lipschitz 的位移（"大 σ、零损伤"的极端构造）

构造 `delta = f * min_gap * centred(rank_asc(P1))`，`f <= 1`。
因为每个相邻斜率都恰为 `f` 或更小，而割线是其所跨相邻斜率的加权平均，故 `q_ij <= f`。取 `f <= 1 < 1.414`：

| f | 幅度 /eV | min gap /eV | tau_b | RMS sigma /eV | q_max | f_unres(z=1) 实测 | f_unres(z=1) 闭式 | top20 overlap |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 0.25 | 0.0028 | 0.0110 | +1.000 | 0.0083 | 0.250 | 0.000 | 0.000 | 1.00 |
| 0.50 | 0.0055 | 0.0110 | +1.000 | 0.0167 | 0.500 | 0.000 | 0.000 | 1.00 |
| 0.75 | 0.0083 | 0.0110 | +1.000 | 0.0250 | 0.750 | 0.000 | 0.000 | 1.00 |
| 1.00 | 0.0110 | 0.0110 | +1.000 | 0.0334 | 1.000 | 0.000 | 0.000 | 1.00 |

`q_max` 精确等于 `f`（该构造的签名）。**`tau_b = +1.000` 与 `f_unresolved = 0.000` 在所有幅度下同时成立。**

**必须纠正一个容易犯的错误**："单调 ⇒ 无 unresolved"是**错的**。
单调的 `delta` 仍可能比目标轴跳得更快（`delta` 的相邻增量大于 `DeltaP` 的相邻间距），
此时 `q_ij > 1` 完全可能。T4 真正收费的是 `delta` 沿目标轴的 **Lipschitz 常数**，
本例把该常数人为压在 `f <= 1` 才得到零 unresolved。
这个区分很重要：它说明 §4 里 `P0->P1 / 还原` 的 `f_unresolved = 0.733` 并不是"位移太大"，
而是"存在若干近简并对，它们的目标轴间距小于该处位移的变化量"。

## 7. 可预测性检验：H_var 从"相关"升级为"可预测"

### 7.1 目标与预测子

- **目标**：该台阶是否**改写 top-20% 候选清单**，即 `overlap < 1`。
  `N = 10` 故 `k = max(1, round(0.20 * 10)) = 2`，这是一个严格的"两槽"测试。

- **预测子**：全部为单变量、零成本（只用到 §2 的 `delta`、`DeltaP`、`sigma`）。
- **检验**：(i) AUC；(ii) **精确**置换 p 值 —— `C(10,3) = 120` 种标签分配可以穷举，不做抽样；
  (iii) 留一（LOO）阈值分类器：阈值在另外 9 个点上重拟合，只预测被留出的那一个点。

### 7.3 结论与诚实边界

**一个被否证的直觉（重要）**：`sigma2_share_residual` 在其**自然假设方向**上得到 `AUC = 0.000`。
直觉会认为"破序（残差）份额越大越危险"，数据给出的恰恰相反：残差份额最大的几个台阶
（`P1->P2`、`G1->G2`、`C1->C2 / 氧化`，份额 0.88–0.98）一个都没改写清单；
而三个改写点的残差份额分别是 0.292 / 0.415 / 0.642。真正危险的是**平行份额大**。
机制上这与 §3.5 的警告一致：一个**强负**斜率既让位移"与轴平行"（平行份额大），
又让排序面临反转。所以"σ² 预算的哪一半更危险"这个问题的答案，与不看符号时的直觉相反。
（两个份额互为 `1 − x`，因此它们是同一信息的两种朝向，**不是两个独立证据**。）

**结论（肯定）**：清单改写**是可预测的**，但预测子必须是**方向敏感**的 ——
带符号斜率 `ols_slope_b` 达到 `AUC = 1.000`、精确置换 `p = 1/120 = 0.0083`、LOO 10/10。
机制上完全透明（§5）：`b < 0` 意味着**廉价方法的误差与稳定性轴反相关** ——
它系统性低估"目标轴偏好的分子"、或高估"不偏好的分子"，
这类误差恰好集中在候选清单所在的分布尾部，因此**专门破坏决策**而不是整体平移。
`b > 0` 则是"拉伸"：分辨率下降，顺序不动。

**边界（必须同时说清）**：

1. **两个 AUC = 1.000 的预测子本质是同一信息。**
   平行份额与残差份额互为 `1 − x`；平行份额与带符号斜率通过 `b` 与 `var(P1)/var(delta)` 相关。
   表中"两个满分"不应被读成"两个独立验证"。
2. **n = 10、3 个正例下，1.000 / 0.905 / 0.857 之间统计上不可区分**
   （精确 p 为 0.008 / 0.033 / 0.058，区间严重重叠）。**不得**报告"AUC 1.000 优于 0.857"这类排序。
3. **唯一稳健、可对外陈述的一句话**是：
   **方向敏感的预测子一致优于无符号的量级代理** —— `sd(delta)`（0.810）与 `q_median`（0.857）
   这一类别恰好漏掉了那个 2.25 eV 的反例（§4 第 2 行：`sd` 全篇最大、清单完好）。
4. **LOO 10/10 不是外部验证。** 阈值是在同一批 10 个点上重拟合的；它证明的是"存在一个一致的阈值规则"，
   而不是"该规则能外推到新分子/新台阶"。真正的外推检验需要新增分子或新增台阶。
   **Week 21 已补上这一检验**：把本节的规则冻结在 10 个发现点上，再作用到从未参与阈值选择的分子集上
   （§7.4）。结论是**部分外推成立**：带符号规则 3/4，朴素（无符号 `sd(delta)`）规则 2/4。
5. **目标函数的选择本身是一个自由度。** 这里用 `overlap < 1`（两槽）。若改用 `tau_b < 0.5`
   或 `1 − tau_b` 连续目标，排序会变。`rank_damage_1_minus_tau` 在两种口径下都接近满分，
   是本阶段最不依赖口径选择的一个量。

## 9. 物理读法：H_var 的正确陈述

Week 9 把中心命题写成"位移的**散布**决定排序是否幸存"。本阶段证明这个写法**不准确**，
并给出正确的版本：

> **H_var\***：一个台阶是否破坏决策，取决于**方法位移相对目标轴的斜率分布**与临界值
> `sqrt(2)/z` 的关系；而不是取决于位移的散布大小。位移的散布只是它的一个粗代理。

由 §5 的相图，三种失效模式全部由斜率 `b` 控制（z = 1）：

| b 区间 | 排序（tau_b） | 分辨率（f_unresolved, z=1） | 现实对应 |
| --- | --- | --- | --- |
| `b > 1.414` | 保序（+1） | **全部不可分辨** | `P0->P1 / 还原`：b = +2.03，f_unres = 0.733，但清单完好 |
| `0.722 < b < 1.414` | 保序 | 全部可分辨 | —— |
| `-0.722 < b < 0.722` | 保序 | 全部可分辨 | `G1->G2`、`P1->P2 / 氧化` 等（最安全区） |
| `-1.414 < b < -0.722` | 保序 | 全部可分辨 | `C1->C2 / 还原`（b = -0.772）——**清单被改写但全局排序未反转** |
| `-1 < b <= -1.414` 之外 | 保序 | —— | `P0->P1 / 氧化`（b = -0.599） |
| `b < -1` | **反转（-1）** | —— | `C0->C1 / 还原`：b = -2.32，tau_b = -0.467 |

（表中"保序"指 `tau_b` 为正；实数上 `delta` 并非严格线性，故 `tau_b` 是介于 0 与 1 之间的数，
上表是线性极限下的定性分区。）

**物理机制（两句话）**：

- **`b < 0`：方法误差与稳定性轴反相关。** 廉价方法对"目标轴偏好的分子"系统性低估
  （或对"不偏好的分子"高估）。这类误差**恰好集中在候选清单所在的分布尾部**，
  因此专门破坏决策，而不是整体平移。这是危险的那一类。
- **`b > 0`：方法误差与稳定性轴正相关（"拉伸"）。** 分辨率下降（近简并对越界），
  但顺序保持。清单完好。`|b|` 进一步超过 `sqrt(2)/z` 时，`f_unresolved` 饱和到 1 ——
  排序还在，但你已无法用任何置信水平声称它。

**一个可操作的推论**：把 T1–T4 合起来看，`H_var` 的"成本"只有两项 ——
**斜率的大小对分辨率收费，斜率的符号对排序收费**。均匀偏差（T3）不收费。
