# Week 13 报告 —— Stage 14：畸变项的定量归因，与 EMC 离群点的病理裁决

## 0. 一句话结论

Week 12 把环境位移精确拆成四项之后，留下了两个「已知但没有被解释」的东西：
被量化却未被归因的**畸变项**，和 24 条曲线里唯一非单调的 **EMC 还原轴**。
本周把两者一起裁决，得到一个结构性结果与一个否定性结果：

1. **畸变项不是一项，是两个单态惩罚之差**。定义
   `D_态(t) = bare(X,t) − bare(X,gas)`（`bare` = 同一次自洽计算里摘掉 CPCM 介电项与
   SMD CDS 项之后的电子能量），则

   ```
   dist_oxidation = D_cation − D_neutral
   dist_reduction = D_neutral − D_anion
   ```

   该恒等式在 **192 个「分子 × 层」行**上重建，最大残差 **6.7e-12 eV**；
   五项位移恒等式 `d_total = diel + dist + cds + d4gcp + residual` 在 **216 行**上
   残差**恰为 0**。逐态惩罚 `D_neutral = 0.0685`、`D_cation = 0.1120`、
   `D_anion = 0.3710 eV`，并且 **72/72 全部为正**（最差 +0.0113 eV）——
   **变分检验无例外**：溶剂自适应密度不是裸电子能量的极小点，因此「弛豫回去」不可能降能。
2. **通道不对称是阴离子效应，而氧化轴的小均值是相消的产物**。还原/氧化位移之比
   **6.95 倍**；还原轴 **12/12 个分子为负**，氧化轴只有 **8/12** 为负，
   均值 +0.0435 eV 由 **EC（+0.2939）、TMP（+0.2096）、PC（+0.1689）** 三个分子撑起。
   「畸变把环境位移拿回多少」在氧化轴上**是一个分子依赖的性质，不能报一个均值了事**。
3. **归因只成功一半，而失败的那一半是最重要的那一半**。唯一稳健的关系是
   `D_neutral` 对分子自身气相偶极矩（Spearman rho = **+0.909**，p = 4.2e-05，
   留一 R² = **0.634**，斜率 0.0154 eV/D）。**`D_anion` 的最佳描述符留一 R² 只有 0.162**，
   且阴离子自身的气相偶极几乎无关（rho +0.062，p = 0.61）。这是一个**否定性结果**：
   决定通道不对称的那一项，需要「新增电子的空间弥散度」来描述，而仓库里任何已存量都不测它。
4. **Week 12 §14 公布的那对均值是错的**。510 种「层子集 × 符号」聚合逐一枚举，
   在 1e-6 eV 内**精确命中 0 个**；最接近者仍差 1.22 meV。可复现值是
   **+0.0435 / −0.3025 eV**（逐分子先平均，6 个 bare CPCM 层）。
5. **EMC 离群点 = `solution-selection artefact`（bare CPCM 的 SCF 解选择伪影）**。
   不是粗网格（加密九点后 R² 从 0.8468 **掉到** 0.6788、符号变化 2 → 4 次），
   不是数值噪声（粗糙度 1.99 对光滑总体中位数 0.235）。**决定性证据来自独立观测量**：
   EMC 阴离子的**偶极**在九个介电点上于两组值之间跳变 4 次（~2.5 D vs ~6.3–7.1 D），
   且与能量跳变同相；36 条偶极阶梯里只有这 1 条可疑，12 个分子里只有 EMC 的
   `EA(eps)` 二阶差分异常。

### 2.2 本周新增的三条口径

1. **`bare` 的操作性定义**（此前只隐含存在）：

   ```
   bare(X, t) = Total Energy(X, t) − CPCM dielectric(X, t) − SMD CDS(X, t)
   ```

   三个量都取自**同一次**自洽计算的打印分项，所以 `bare` 是「电子能量 + 核排斥」，
   几何不变而密度已含环境响应。
2. **`dist_ev` 的符号语义**（Week 12 只用未定义）：

   ```
   dist_ev 是「对环境位移的一项贡献」，正号 = 把位移往同方向推
   ```

   对氧化轴，介电项 `diel_ev` 是负的（溶剂降低 IP），而 `dist_ev` 通常为正，
   即**畸变是「拿回」介电位移的项**。这也解释了为什么 §14 会写出那对可疑均值：
   畸变项的正负号在氧化轴上逐分子不同，符号怎么取会大幅改变均值。
3. **归因的独立性口径**：`D_态` 的六个介电层**不是六个独立测量**，
   因此所有相关性分析**先把六个层对每个分子平均**，得到 12 个点（每个分子 1 个点）。
   本周报告与 JSON 里所有 `rho`/`p`/留一 R² 都是 n = 12。
   （`stage14_attribution.json → correlations.state_penalty.pseudoreplication_note`
   写明：`each molecule is one point; the six bare-CPCM layers are averaged first,
   because they are not six independent measurements`。）

## 4. Part A：畸变项的恒等式与逐态身份

### 4.1 两条恒等式

**位移恒等式**（Week 12 已建立，本周复核）：

```
d_total_ev = diel_ev + dist_ev + cds_ev + d4gcp_ev + residual_ev
```

216 行残差**恰为 0**。注意这不是「小于 1e-10」而是**精确 0**：
`residual_ev` 本身就是按此式反解出来的兜底项，它之所以在表里，
是为了让读者能看见「除去四个已命名项之外还剩多少」，而不是为了让恒等式成立。

**惩罚恒等式**（本周新增）：

```
dist_ev = D_hi − D_lo
```

其中氧化轴 `(hi, lo) = (cation, neutral)`、还原轴 `(hi, lo) = (neutral, anion)`。
在 192 个「分子 × 层」行上重建，最大残差 **6.7e-12 eV**（即浮点噪声量级）。

**这条恒等式是本周全部归因工作的前提**，因为它把「一个轴观测量」翻译成了
「两个有明确物理身份的单态量之差」。

### 4.3 ★ 变分检验：72/72 全为正

`D_态 >= 0` 不是经验观察，而是**变分原理的必然要求**。理由：
`bare` 是「溶剂自适应密度」下的裸电子能量；而该密度（在加了环境项之后）是
`Total Energy` 的极小点，一般**不是** `bare` 的极小点。因此把密度「弛豫回」
`bare` 的极小点不可能降低 `bare` —— 只能持平或升高。所以

```
D_态 = bare(溶剂密度) − bare(气相密度) >= 0
```

- 观察到的最小值：**+0.0113 eV**（cation 通道，某个分子某一层）。
- 没有任何一行 ≤ 0（容差 −1e-9 eV 也没触及）。
- `variational_check.all_penalties_non_negative = true`。

这条检验的价值在于**它是一个独立的物理一致性检查**：如果 `bare` 的定义里
少减了或多减了某一项（例如忘了 CDS，或把 `diel_ev` 减了两次），
就必然出现大面积的负惩罚。**72/72 全正，说明 `bare` 的分项摘除是自洽的。**

## 5. Part A：通道不对称是阴离子效应

把 `dist_ev` 先对六个层平均（每分子一个值），再对 12 个分子平均：

### 5.1 氧化轴的小均值是「相消」而不是「小效应」

逐分子分解（六个层的均值，eV）：

| 分子 | dist 氧化 | dist 还原 |
| --- | --- | --- |
| EC | **+0.2939** | −0.6558 |
| TMP | **+0.2096** | −0.1460 |
| PC | **+0.1689** | −0.7591 |
| SN | +0.0122 | −0.0387 |
| DMC | −0.0058 | −0.1156 |
| DOL | −0.0060 | −0.2030 |
| DME | −0.0070 | −0.5431 |
| EMC | −0.0094 | −0.3289 |
| SL | −0.0187 | −0.3876 |
| AN | −0.0267 | −0.2266 |
| DMSO | −0.0399 | −0.0829 |
| GBL | −0.0487 | −0.1432 |

氧化轴有 **4 个正、8 个负**，正的三项（EC/TMP/PC）把均值从 −0.02 量级抬到 +0.0435；
还原轴 **12 个全负**，没有相消。因此：

> **还原轴的畸变是「系统性的、结构性的」；氧化轴的畸变是「分子依赖的、近乎抵消的」。**
> 报一个氧化轴均值会掩盖真实结构，Week 12 §14 就是在这里出错的。

### 5.2 为什么是阴离子

`D_anion = 0.3710 eV` 是 `D_neutral = 0.0685 eV` 的 **5.4 倍**、
`D_cation = 0.1120 eV` 的 **3.3 倍**。物理解释直接：

- **阳离子**：电子密度被抽走，分子变小、更「硬」，环境反应场对它做的工作小。
- **阴离子**：新增电子占据的是**弥散、松散束缚**的轨道，其空间范围大，
  对腔外屏蔽最敏感。溶剂把密度往外推得越远，`bare` 的能量相对气相就升高得越多。
- **中性**：只有永久偶极被环境再极化，代价最小。

**因此「通道不对称」的物理名字应该是「阴离子弥散轨道的环境响应」，而不是
「介电屏蔽对不同电荷态不等」。** 后者是现象，前者是机制。
## 6. Part A：归因筛选（14 个描述符 × 5 个目标，n = 12）

### 6.1 方法

- **描述符**共 14 个：
  `mu_neutral_debye`、`mu_cation_debye`、`mu_anion_debye`（三个态的**气相**偶极，
  来自 `outputs/week4/orca/`）、`mu_anion_smd_acn_debye`（**SMD 乙腈里**的阴离子偶极）、
  `dmu_oxidation_debye`、`dmu_reduction_debye`（两轴的偶极变化）、
  `dipole_debye`（P0 的中性偶极）、`aux_alpha_bohr3`（xtb 静态极化率）、
  `homo_ev`、`lumo_ev`、`hl_gap_ev`、`atom_count`、`p0_ox_ev`、`p0_red_ev`。
- **目标**共 5 个：三个逐态惩罚 `D_neutral`/`D_cation`/`D_anion`，两个轴观测量
  `dist_oxidation`/`dist_reduction`。
- **独立性**：六个介电层先对每个分子平均 → n = 12。
- **打分用留一交叉验证 R²**，不是拟合 R²。理由：n = 12 且每个模型只有 1 个自变量，
  拟合 R² 会被单个杠杆点抬高；留一 R² 会惩罚这种「单点撑起来的拟合」
  （本周单测里就有 `test_ols_leave_one_out_penalises_a_single_point_fit`）。

### 6.2 结果

| 目标 | 最佳描述符 | rho | p | 留一 R² | 判定 |
| --- | --- | --- | --- | --- | --- |
| D_neutral | `mu_neutral_debye` | **+0.909** | 4.19e-05 | **0.634** | ✅ 稳健 |
| D_neutral | `mu_cation_debye`（次优） | +0.881 | 1.53e-04 | 0.578 | ✅ |
| D_cation | `homo_ev` | −0.406 | 0.191 | 0.071 | ❌ |
| D_anion | `mu_anion_smd_acn_debye` | **+0.629** | 0.028 | **0.162** | ❌ |
| dist_oxidation | `homo_ev` | −0.664 | 0.0185 | 0.120 | ❌ |
| dist_reduction | `mu_anion_smd_acn_debye` | −0.427 | 0.167 | 0.075 | ❌ |

**只有 `D_neutral` 这一行是稳的**，而且它同时被三个不同的偶极量稳健地捕捉
（`mu_neutral_debye` 0.634、`mu_cation_debye` 0.578、`dipole_debye` 0.573）——
互相印证，不是偶然。OLS 给出

```
D_neutral = 0.0180 + 0.0154 * mu_neutral_debye     (eV, D)
```

也就是说：**中和态的畸变就是「溶剂把这个极性分子重新极化」的代价**，
斜率 0.015 eV/D 量级合理（典型偶极 1–5 D，代价 0.03–0.09 eV）。

### 6.3 ★ 否定性结果：阴离子畸变无法用已存量预测

这是本周最重要的负结果，要写清楚三点：

1. **最佳留一 R² 只有 0.162**。即使让步到「有信号但不用于预报」，
   n = 12 上 0.162 与 0 不可区分。
2. **阴离子自身的气相偶极几乎完全无关**：`mu_anion_debye` 的 rho = **+0.126**，
   p = **0.697**，留一 R² = **−0.451**（负值 = 比用均值预测更差）。
   也就是说，「阴离子在气相里有多大的偶极」**不测**它被溶剂推挤的代价。
3. **唯一有点相关的是「阴离子在 SMD 乙腈里的偶极」**（rho = +0.629，p = 0.028），
   而它的留一 R² 也只有 0.162。这条线索本身有物理含义：
   **决定畸变代价的是「电子加进去之后，密度在溶剂里长成什么样」，
   而不是「它在气相里是什么样」。**

顺带记录两个「零结果」，避免以后重复尝试：

- **`aux_alpha_bohr3`（xtb 静态极化率）对所有五个目标都几乎无相关**
  （阴离子组 rho = +0.105，p = 0.746）。极化率不是这个问题的正确变量。
- **两个轴观测量都不可预测**（最好留一 R² 分别为 0.120 / 0.075）。
  氧化轴的 `homo_ev` rho = −0.664、p = 0.0185 看着像真信号，
  但**留一 R² 只有 0.120** —— 在 n = 12 上这是「一个点撑着」的典型形态。
  **Week 11 的事前预警协议不应接入它**（否则就是把 Week 11「阈值从 3 个正例读出」
  的错误再犯一次）。

### 6.4 缺的是什么量

Part A 的结论可以写成一句可操作的话：

> **需要一个新的描述符：阴离子「新增电子的空间弥散度」。**

候选实现（留作 Week 14 候选 5）：
- 阴离子 HOMO 的**空间范围**（例如 `⟨r²⟩` 或径向二阶矩）；
- 阴离子与中性分子的**差分密度**的 `⟨r²⟩`（真正测「新增电子的弥散」）；
- 阴离子的**绝热电子亲和能**与**垂直 EA** 之差（间接反映弛豫幅度）；
- 用 xtb 的 Mulliken/Löwdin 布居算「新增电子分布在外层原子上的比例」。

四个都不依赖新方法，只用已有引擎。

## 9. Part B：偶极解身份筛查与裁决

### 9.1 为什么必须用偶极，而不能用能量

如果用能量自己去证「能量跳变是解跳变」，就是**循环论证**。
ORCA 输出里有一个**完全独立、且与能量无因果关系**的量：**总偶极矩**
（`Total Dipole Moment` 块后的 `Magnitude (Debye)`，取最后一个块）。
两个不同的 SCF 解会有不同的偶极，而同一个解在不同介电常数下的偶极只会平滑变化。
**这给出一个可证伪的判据**：

> 如果只是「粗网格 + 光滑曲线」，偶极应当逐点光滑；
> 如果真是「解跳变」，偶极应当与能量**同相跳变**。

### 9.2 ★ 36 条偶极阶梯里只有 1 条可疑

筛查覆盖 **12 个分子 × 3 个电荷态 = 36 条偶极序列**，每条在**六个共享 bare CPCM 层**
（eps = 5/10/20/40/80/200）上取值。EMC / DMC / EC 三分子另有九点阶梯，
用来观察分支跳变的完整形态（`solution_identity_screen()`）。

**EMC 阴离子的偶极按 eps（Debye）：**

```
5 -> 2.538   7 -> 6.300   10 -> 6.647   14 -> 6.870   20 -> 2.499
28 -> 7.145  40 -> 2.542  80 -> 2.556   200 -> 2.564
```

**两个 SCF 解在交替**：低分支 ≈ 2.5 D（5 / 20 / 40 / 80 / 200）、
高分支 ≈ 6.3–7.1 D（7 / 10 / 14 / 28）。九点里**跳变 4 次**。
而能量的跳变与它**同相**（20 与 40 处能量也掉下来）。

粗糙度定义：`max |二阶差分| / span`（对 eps 的**等距性不敏感**，
因为它只用同一序列内部的差分）。

| 序列 | `max abs 2nd diff` (D) | span (D) | 粗糙度 |
| --- | --- | --- | --- |
| **EMC / anion** | **9.248** | 4.646 | **1.99** |
| DMC / reduction（对照） | — | — | **0.069** |
| EC / reduction（对照） | — | — | **0.085** |
| 光滑总体中位数（其余 35 条） | — | — | **0.235** |

**判据结果：36 条里恰好 1 条可疑 —— EMC/anion。**
而且 EMC 的**中性态与阳离子态偶极完全光滑**（见 `stage14_outlier.json` 的
`emc_anion_solution_switches` 与 `dmc_anion_solution_switches`：
EMC 阴离子在共享四点上就发生了分支切换，而 DMC 是 0 次）。

### 9.3 独立佐证：`EA(eps)` 的「跨分子」二阶差分

用能量做的第二条佐证，思路是**换掉比较对象**：
不是「同一条曲线自己光不光滑」（那就循环了），而是

> **12 个分子里，是不是只有 1 个的 `EA(eps)` 比另外 11 个更崎岖？**

「跨分子」这个比较维度不能由「同一批能量喂给 Born 拟合」这件事产生，
所以它不构成循环论证。实现见 `analyze_stage14_outlier.py → energy_kink_screen()`，
输入是**六个共享 bare CPCM 层**上的 12 个分子 × 3 态冻结能量
（5/10/20/40 来自 `outputs/week4/`，80/200 来自 `outputs/week12/`）。

度量：在**介电索引**上取二阶差分 `y[i+1] − 2y[i] + y[i−1]`，
再对六点取绝对值最大者（单位 eV）。

**还原轴 `EA(eps)`（12 个分子排序，前三）：**

| 排名 | 分子 | `max abs 2nd diff` (eV) |
| --- | --- | --- |
| 1 | **EMC** | **0.5369** |
| 2 | DOL | 0.1483 |
| 3 | AN | 0.1411 |

**对照组 `IP(eps)`（同样 12 个分子）：**

| 排名 | 分子 | `max abs 2nd diff` (eV) |
| --- | --- | --- |
| 1 | EC | 0.1434 |
| 2 | AN | 0.1380 |
| 3 | DOL | 0.1276 |
| — | **EMC** | **0.1066**（落在中间，完全正常） |

两条结论：

1. **EMC 是 `EA(eps)` 上唯一的离群，超出次名 3.62 倍**（0.5369 / 0.1483）。
   其余 11 个全部 ≤ 0.1483 eV，彼此相差无几。
2. **在 `IP(eps)` 上 EMC 不是离群**（0.1066 eV，排在 EC / AN / DOL 之后）。
   也就是说这个异常**只出现在还原侧**，与 §6 的「阴离子畸变主导通道不对称」
   完全吻合 —— 一个纯粹的能量侧观察，独立指向同一个结论。

两条佐证（偶极 + 跨分子能量）互相独立、互不循环，共同把裁决钉死在
`solution-selection artefact` 上。

### 9.4 裁决与物理图像

> **EMC 还原轴的离群点 = `solution-selection artefact`（bare CPCM 的 SCF 解选择伪影）。**
> **既不是粗网格，也不是数值噪声。**

物理图像：EMC 阴离子在极化连续介质中**有两个能量接近的 SCF 解**，
对应阴离子电子密度的两种形变 —— 直观地说，多出来的那个电子
是**「贴在内侧」**（靠近羰基/酯基，偶极小 ≈ 2.5 D），
还是**「铺到外侧」**（云状弥散在分子外围，偶极大 ≈ 6.3–7.1 D）。
介电常数改变腔外屏蔽，二者能量次序在 **eps ≈ 10–20 之间翻转**。
ORCA 每次从默认初猜出发收敛到**局部**极小点，于是落点随机，
求出的 `EA(eps)` 就出现锯齿。

**关键限定**：

- 这是**一个分子的一条曲线**的局部事故，**不构成对 Born 形式的反例**。
  同族的 DMC（直链碳酸酯）还原轴 R² = 0.9984、EC（环状碳酸酯）0.9590，
  都在 0.96 以上。
- 它**只影响** `EA(EMC)` 的**介电依赖性**；EMC 的气相 EA、
  以及其他 11 个分子的全部量**都不受影响**。
- 由于 Stage 13 / Stage 14 的全部排序结论都建立在**同族同口径的比较**上，
  这一个伪影**不改变任何排序结论**。

**方法论收益**：我们从此有了一个**廉价的、与能量无关的解身份探针**——
「打印偶极 + 算粗糙度」。今后任何溶剂化计算只要出现非单调，都可以先跑这个筛查，
再决定是补点、换初猜，还是改方法。

## 10. 物理读法

### 10.1 环境层里的三项，物理身份各不相同

| 项 | 物理身份 | 量级（SMD 乙腈，氧化轴） |
| --- | --- | --- |
| `diel_ev` | 纯静电屏蔽（Born/Onsager 反应场） | 主导，负 |
| `dist_ev` | **溶剂自适应密度带来的电子再极化代价** | 3.14% 反号（Week 12 结论） |
| `cds_ev` / `d4gcp_ev` | 空腔/色散/几何项 | 对垂直量精确为 0 |

本周把第二项的**来源**定死了：它**不是**「分子被压扁了」，
而是**「密度被环境推动」**，且推动幅度**对阴离子最大**（0.3710 eV）。

### 10.2 畸变代价的排序是「阴离子 ≫ 阳离子 ≳ 中性」

```
D_anion (0.3710) : D_cation (0.1120) : D_neutral (0.0685)  ~  5.4 : 1.6 : 1
```

这条排序有直接的化学后果：**任何「垂直量」（垂直 IP / 垂直 EA）的溶剂位移，
在还原侧都会被打一个大折扣**，因为阴离子把一部分溶剂化能「还回去」了。
这也是为什么还原轴位移总是被畸变拿回得更多（12/12 分子）。

### 10.3 中和态的畸变 = 偶极再极化（本周唯一的定量机制）

`D_neutral = 0.0180 + 0.0154 mu` 这条直线（r² = 0.762，留一 0.634）
是**本阶段唯一可用的定量机制**：只要知道分子的气相偶极，就能事前估出
「溶剂会拿回多少中和态的能量」。对典型溶剂（偶极 1–5 D）：
`D_neutral ≈ 0.03–0.09 eV`。

### 10.4 为什么阴离子畸变测不出来 —— 物理原因

不是因为「描述符不够多」，而是因为**存量描述符测的都是基态性质**：

- `mu_anion_debye`（气相阴离子偶极）测的是**已弛豫的**阴离子的形状，
  而畸变代价取决于**垂直过程中**密度的响应——
  这是「绝热」与「垂直」的区别，两者可以完全不同。
- `aux_alpha_bohr3` 测的是**中性基态**的极化率，与「新增一个电子后
  该电子铺多开」无关。

**这正是 Part A 点名要的量：新增电子的空间弥散度。**

## 14. 遗留与需裁决项

1. **【新】阴离子弥散度描述符缺失**：Part A 的否定性结果直接点名了需要的量——

2. **【新】更鲁棒的 SCF 解选择**：EMC 阴离子的双解问题在 bare CPCM 下没有自动

   `%scf` 的 `GuessMode` / `SOSCF` 设置、或对同一点跑两次不同初猜取更低解。
   **是否值得**为一个分子引入额外作业？

   （C 2.04 → 1.85 Å 等），ORCA 的 `%cpcm` 不暴露腔半径。是否改用显式 `$radii`
   在 eps = 32/78 上做一次真正的分离（72 个作业）？
4. **【延续】eps = 1000 实测点**：导体极限目前是拟合斜率的外推
   （Week 12 显示缺口 < 33 meV）。是否需要实测？
5. **【延续】预警规则阈值外部验证**：Week 11 的阈值仍是在同一批 10 个点上读出的。
   本周新增了一条「不应接入」的负面结论，但**仍缺外部验证**。
6. **【延续】Gate 1 NOT CLOSED**：唯一 blocker 仍是溶液锚点 31 行 `method = est`。
   **任何后续周的动作都不能关闭它，只有补齐溶液锚点才行。**
