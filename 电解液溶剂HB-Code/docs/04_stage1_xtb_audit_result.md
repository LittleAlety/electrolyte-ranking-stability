## 1. 做法

审计集取 core set 中**有已核验气相锚点**的 12 个闭壳层分子（EC, PC, DMC, DEC, DME, DOL, EA, GBL, SL, DMSO, AN, TMP）。
每个分子在 GFN2 下做 5 个计算：中性优化、阳离子单点（中性几何）、阳离子优化、阴离子优化、中性单点（阴离子几何）。

- **垂直 IP/EA**：ΔSCF，固定参考几何 —— 对应光电子谱测量的量，因而是与锚点（PE 值）可比的量。
- **绝热 IP/EA**：两个态都弛豫 —— v2 §3.1 中 $P_1$ 目标量的定义。
- **Koopmans 代理**：$-\varepsilon_\mathrm{HOMO}$ / $-\varepsilon_\mathrm{LUMO}$ —— 即 v2 §3.1 的 $P_0$。

## 3. 结论（本轮最有分量的结果）

### 3.1 「值误差 ≠ 排序误差」被实测证实

ΔSCF 的值误差是 Koopmans 代理的 **3.4 倍**（4.45 vs 1.32 eV），但它的**排序一致性反而更好**
（tau_b 0.911 vs 0.689）。这正是 v2 §1.2 与 §22.2 想说的情形：一个"数值更差"的量仍然能保持材料排序。

### 3.2 ΔSCF 的误差几乎是**常数平移**，不是重排

ΔSCF 误差的标准差只有 **0.343 eV**，而偏差达 4.451 eV —— 即误差主要是一个公共 offset。
按 v2 §22.2，这类 offset 不改变 pairwise order，廉价模型仍可能"足以支撑筛选"。

### 3.3 但对本项目的直接含义是**反直觉**的

在 GFN2 这一层，把 $P_0$（轨道代理）换成 $P_1$（气相 redox 热力学）**并没有更接近实验**，
反而在绝对值上差得多。这与 v2 的核心命题一致：

$$
\text{model complexity} \neq \text{accuracy}
$$

**注意：这不能推广成"永远用 Koopmans 更好"。** 它只说明：在 GFN2 这个特定层级、对这 10 个分子、
以气相 PE 值作为参考时，$P_0$ 的数值更接近参考。是否在 r2SCAN-3c 层仍然如此，必须由审计的第二臂回答。

## 4. 必须写明的 caveat

1. **n = 10**。tau_b 的抽样不确定性很大（此量级下 95% 区间约 ±0.2），不能据此宣称稳健排序结论。
2. **参考量是 PE 近垂直值**，与 ΔSCF 垂直量同类型，但与绝热 IP 不同类；绝热 IP 系统性更低。
3. **GFN2 对气相离子本就弱**：tight-binding 参数主要拟合中性分子，ΔSCF 正偏差 4–5 eV 是方法固有特征，
   不是实现错误（已用手工复算 water 校验：ΔSCF 垂直 IP 18.29 eV，与代码一致）。
4. **阴离子的 unbound 判定对起始几何敏感**：EC 自由基阴离子从 RDKit 几何出发给出 HOMO +0.573 eV（`unbound_anion`），
   从优化后的中性几何出发给出 HOMO -0.931 eV（判定为束缚）。即 EC 阴离子存在**两个不同极小**。
   在 v2 §6.4 的 state identity QC 落地之前，`unbound_anion` 只能当作**待确认标记**，不能当作稳健态标签。
5. **EA 锚点仅 2 个且数值可疑**（DMSO 0.014 eV、AN 0.011 eV），不足以支撑任何 EA 结论。
