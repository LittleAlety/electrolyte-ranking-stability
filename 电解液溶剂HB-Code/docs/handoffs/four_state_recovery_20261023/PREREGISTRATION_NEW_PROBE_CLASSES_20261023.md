# 两类新探针的预注册（2026-10-23，**提交前必须先冻结**）

依据 P3 诊断：DOL/EC 的**登记扭转数为 0**（五元环刚性）；环 pucker 的合法振幅只能产生
**0.0199–0.0771 Å** 的重骨架位移，而放大到能产生大位移会把环键拉断。于是这两个态的
**大位移自由度**只能来自**声明式 Li 配位探针**。二者都是**新探针类**，按项目纪律
（"任何新起点/新方法必须先预注册：方法唯一定义 / 成本上限 / 停止条件 / 不回填旧池"）
在此冻结定义。**本文件不授予提交权限**。

## 探针类 A：`ring_pucker`（合法环形变）

| 项 | 冻结定义 |
|---|---|
| **方法唯一定义** | 取该态**代表成员**几何；由键级拓扑找 ≤7 元环（`ring_atoms`）；对环原子取 SVD 最小奇异向量作为环法向 `n`；按三种模式位移：`envelope`（`ring[0]`）、`twist`（`ring[0]` 与 `ring[len/2]` 反向）、`envelope2`（`ring[len/3]`）；振幅 ∈ {±0.25, ±0.40, ±0.60, ±0.80} Å；**不使用** C=O 伪扭转、**不使用**刚体旋转、**不切断任何键** |
| **准入判据** | 必须过 `validate_candidate_start`：共价拓扑完整（无丢失/新增键）、非刚体、与源及任一已接受起点**不等价**、Li 首壳**未变**。接受者类别 = `heavy_fragment_torsion` |
| **实测可用窗口** | 振幅 ≤0.40 Å 全部接受；**±0.60 / ±0.80 被 `ring_broken` 拒收**（会拉断环键）→ 该窗口即几何上限，**不得绕过** |
| **成本上限** | 每态 ≤32 个原始候选（本机生成，零超算成本）；GFN2 筛选计入筛选额度 ≤32 core-hours 总量 |
| **停止条件** | ① GFN2 结果全部塌缩回**已知盆地** → 停止，按"覆盖探针"分支处理并**如实报告**，**不伪称新极小**；② 出现明显的不同盆地 → 交 P4 建生产包；③ 预算耗尽 → 停止并记录 |
| **不回填旧池** | 新候选只进入**本轮新版本包**；**不得**回填 44 accepted 的历史池，**不得**改动 48 分母 |

## 探针类 B：`li_coordination_change`（声明式 Li 配位/给体方向）

| 项 | 冻结定义 |
|---|---|
| **方法唯一定义** | 取该态代表成员几何；确定每个 Li 的**首壳**（截距 **2.6 Å**，`_li_first_shell`）；把 Li 沿每个给体方向 `toward_<donor>` 与壳层质心方向 `toward_shell_centroid` 平移 **0.15 / 0.30 / 0.45 Å**；候选必须在 `validate_candidate_start(..., declared_li_change=True)` 下**显式声明** |
| **准入判据** | 必须过同一道 gate，且：共价拓扑完整（**Li 关联边不计入共价**——Li···O 是配位）、非刚体、与源及任一已接受起点不等价；**接受者类别 = `ok_li_coordination_change`**（自己的类，**绝不冒充扭转**），并在 detail 记录 source/candidate 壳层 |
| **为何必须声明** | 实测：未声明时，改变首壳成员的候选一律被拒（`li_coordination_changed`）；**0.15 Å 位移若不改变壳层成员则仍可作为普通 Li 位移被接受**——即"改壳层"与"只挪 Li"是**两个不同事实**，不得混同 |
| **成本上限** | 每态 ≤32 个原始候选（本机零成本）；GFN2 筛选计入筛选额度 |
| **停止条件** | 同上三条；额外要求：若筛选显示配位变化只是**同一盆地的不同配位取向**，如实记"同盆地"而不虚增 `n_unique` |
| **不回填旧池** | 同上；且**不得**把配位探针的结果记作扭转探针的结果（类别不可互换） |

## 两类共同的红线（引用项目既有纪律，不得放宽）

1. **不放宽阈值、不改冻结方法**（wB97X-D4/def2-TZVPD、SMD 乙腈、298.15 K、**解析梯度**、
   VeryTightOpt、AnFreq；五阈值从 `config/production_method_freeze_v1.json` 读）。
2. **48 分母不缩**；`n_limited` **绝不清空**；旧尝试与费用**保留**。
3. **重复命中同一极小只增加覆盖证据，不增加 Boltzmann 简并度**（去重由
   `importer → dedup → coverage review → aggregator` 派生）。
4. **GFN2 的 6 kcal/mol 窗口仅是筛选层**，**不得**与生产级 0.10 kcal/mol 容差混用。
5. 所有 ORCA/xtB 与筛选**只在 Slurm 计算节点**运行；本机只生成/校验/解析；**只用命令桥**（禁裸 ssh）。
6. 新探针覆盖 **DMC|M_plus、DMC|LiM_2plus、DOL|LiM_2plus、EC|LiM_2plus 四个指定态**；
   不扩目标态、不扩分母。
