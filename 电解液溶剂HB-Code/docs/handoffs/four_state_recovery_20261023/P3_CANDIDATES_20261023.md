# P3 候选池（2026-10-23，**本机生成 + gate 校验**）

机器可读版本：`P3_CANDIDATES_20261023.json`。**本文件不构成提交授权**；GFN2 筛选与任何生产运行
都必须在 **Slurm 计算节点**执行（本机只做生成/校验/解析）。

## 0. 生成规则（全部实测满足）

| 规则 | 落实 |
|---|---|
| 每个候选都过**同一道** `validate_candidate_start` | 生成器**不绕 gate**；由 `select_candidates` 统一调用 |
| 先做键级拓扑/对称/刚体/碰撞去重 | gate 内部门序：单键轴 → 刚体 → Li 首壳 → 共价拓扑 → 等价 → 分类 |
| 去重必须带 `prior_starts` | `select_candidates` 把**已接受**的作为 prior 传入（实测 7 个登记二面角只对应 **2–3 个不同操作**） |
| 每候选留证 | 源几何 SHA256 / 结果距离指纹 / 移动原子 / 独立性类别 / gate 原因 / pair 与 heavy 位移 |
| 每态 ≤2 组种子、每组 ≤32 原始候选 | 组 1 = 登记二面角；组 2 = 新自由度（环 pucker + Li 配位）；各组 ≤32 |
| **每态 ≤2 个独立生产起点** | 由 P4 在接受的候选中选取（本文件列全部接受项，供选取） |

**新自由度两类**：`ring_pucker`（沿环法向位移环原子：envelope/twist/envelope2 × 振幅 ±0.25/±0.40/±0.60/±0.80）、
`li_coordination`（把 Li 沿每个给体方向与壳层质心方向移动 0.15/0.30/0.45 Å，**声明式**）。

## 1. 逐态结果

| 态 | 环 | 组1（登记二面角，排除无效 v1 刚性族） | 组2（新自由度） |
|---|---|---|---|
| `DMC\|M_plus` | 无 | 7 raw → **接受 3**（heavy **0.2743 / 0.2432** ＋ 1 个**甲基转子 heavy=0**）/ 拒 4 | 0（无环、无 Li） |
| `DMC\|LiM_2plus` | 无 | 7 raw → **接受 1**（heavy **0.4874**）/ 拒 6（1 等价 ＋ **5 需声明配位**） | 6 raw → **接受 3**（Li 探针 heavy **0.15 / 0.30 / 0.45**）/ 拒 3（等价） |
| `DOL\|LiM_2plus` | 5 元环 `[0,1,2,3,4]` | 0（无登记扭转） | 30 raw → **接受 9**（pucker heavy **0.0375–0.0771** 共 6；Li 探针 **0.15/0.30/0.45** 共 3）/ 拒 21 |
| `EC\|LiM_2plus` | 5 元环 `[0,1,2,3,5]` | 0（无登记扭转） | 30 raw → **接受 9**（pucker heavy **0.0199–0.0549** 共 6；Li 探针 **0.15/0.30/0.45** 共 3）/ 拒 21 |

**拒收原因分布（实测）**：DMC|LiM_2plus 组1 = 1×`equivalent_start` + 5×`li_coordination_changed`；
DOL/EC 组2 = 12 条**过大振幅**（±0.60/±0.80）被 **`ring_broken`** 正确拒收（会把环键拉断）。

## 2. 三条**诚实的读法**（不得省略）

1. **甲基转子不算重骨架搜索证据**：`DMC|M_plus` 接受的 3 项里有 1 项 `heavy_change = 0` ——
   它只能复现/否证**该转子自身**的极小，**不得**当作新盆地证据（P2 已定级）。
2. **环 pucker 的重骨架位移很小（0.0199–0.0771 Å）**，远低于项目自己的 **0.35 Å 盆地分离**经验规则；
   而把它放大到能产生大位移的振幅（±0.60/±0.80）**会把环键拉断**（被 `ring_broken` 拒收）。
   → **结论：DOL/EC 若只靠环 pucker，很可能根本无法到达另一个盆地**；这不是预算问题，是几何事实。
3. 因此 **DOL/EC 真正有希望的大位移来自"声明式 Li 配位探针"（0.15–0.45 Å）**，而它们**是新探针类**，
   必须先预注册（见 `PREREGISTRATION_NEW_PROBE_CLASSES_20261023.md`）。**若筛选仍全塌缩，
   按预注册分支处理，并如实填"零"** —— 不伪称 GFN2 新极小。
