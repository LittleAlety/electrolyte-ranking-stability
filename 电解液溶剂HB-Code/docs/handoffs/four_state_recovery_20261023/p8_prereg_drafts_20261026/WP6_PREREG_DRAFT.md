## 1. 范围（引自核心方案 §14，`:386-392`）

- **方法主体**：R=DME（共同参考配体，`C08`，核心方案 §5.1 `:115`），在 **EC、DME、AN、TMP** 四个分子上比较 `[LiM]+/[LiM]2+` 与 `[LiMR]+/[LiMR]2+` 的 redox 差值（`:390`）。
- **cluster 规模**：门槛满足后 **4 cluster × 2 态 × 1–3 motif = 8–24 状态结构**（`:402`）。
- **协议约定**：各态独立弛豫、采样与身份 QC；DME 对应 `[Li(DME)2]+`；统一背景、温度和热化学约定（`:390`）。
- **解释边界**（`:392`）：在同一化学计量内建系综再算 redox 差；不同配体数 cluster 的裸 G 不混合；不把该 check 解释为真实配位概率——它只检验少量关键结论对一个共同显式配体的敏感性。
- **方法基线**：wB97X-D4/def2-TZVPD、SMD(acetonitrile)、VeryTightOpt、AnFreq、原热化学及身份口径，与生产协议一致（GOAL.md:9 冻结口径；WP6 不引入新方法学）。

## 2. 预注册四要素（缺一不可，沿 `second_search_preregistration_draft.md:50-55` 格式）

1. **方法唯一定义**：每 cluster 每 motif 的物种、化学计量、起始构象来源、charge/multiplicity、背景溶剂与热化学约定逐项登记并冻结；R 恒为 DME（`[Li(DME)2]+` 参照）；唯一新增自由度是显式配体 R 的存在与否，其余与生产协议逐项相同。任何协议项变动需另立版本。
2. **成本上限**：见 §3。**占位、待用户定数**——本稿只给情景推算，不构成预算。
3. **停止条件**：每 cluster×motif 组合一轮 Opt+AnFreq；身份 QC 失败（键图改变/物种漂移）按冻结协议「直接判失败、不重试」；预算耗尽即停并出限制报告，不无限续算。每组合最多 1 次有因技术补救（沿用父起点，不伪装新独立起点）。
4. **不回填旧池**：WP6 产物进入**新的版本化池**（`wp6_explicit_ligand_v1`），48 态生产池记录保持原状；WP6 结果不参与改写既有 44 accepted 标签。
