一、计划总览
1.1 项目定位与核心科学问题
本计划是研究方案 v2 的执行层文档：方案回答“为什么做、做什么”，本计划回答“谁来做、按什么顺序做、用什么参数做、做到什么程度算完成、出问题怎么办”。项目研究对象为固定背景电解液中的候选小分子/共溶剂/添加剂，研究目标不是宣称预测完整电池性能，而是系统回答三个核心问题：
哪些缺失物理（溶剂化、Li+ 配位、构象、state identity 变化）只是数值 offset，哪些会产生超出方法不确定性的稳健排序翻转（robust inversion）？
一个明显的排序翻转是否真的大于模型不确定性（robustness 判据）？
在给定且经外部验证的 target model 下，恢复筛选决策（Top-k / 整体排序）所需的最小昂贵计算预算是多少？
第一阶段严格区分四件事：模型复杂度、数值准确性、化学物种状态、材料决策。任何结论都必须通过外部 reference layer 或不确定性审计之后才能下。
1.2 本计划与研究方案 v2 的关系
本计划不改变 v2 的科学定义，只补充执行细节：具体分子清单、软件与参数、逐周时间安排、逐 Stage 的交付物与放行 Gate、计算预算、风险预案。凡本计划与 v2 不一致处，以 v2 的科学定义为准并记录偏差原因。

五、批量计算执行计划（Stage 2–5）
5.1 Stage 2：broad cheap pool（第 3–4 周）
任务：canonical SMILES 生成 3D → RDKit descriptors → CREST/GFN2-xTB 预优化 → 提取 P0 scalar proxies（−ε_HOMO、ε_LUMO、xTB vertical EA proxy）→ 建 X(0) 特征表。
QC：duplicate 检查、chemical-space 覆盖图、xTB 失败样本单独统计。
产出：broad_pool.csv（含 X(0) 与 P0）、cheap chemical-space map 图。
若时间紧张，broad pool 只做到 P0，但结构与 metadata 必须一次性建全。
5.2 Stage 3：core 自由分子电子结构（第 3–4 周并行）
任务：core set 每分子的 neutral/cation/anion 分别做构象搜索与 DFT refinement（不假定共享最优构象），建立 state-specific ensemble（G_q^ens = −RT ln Σ_i g_i exp(−G_q,i/RT)），得到 P1 = ΔG_ox/red^gas。
QC：阴离子非束缚态标 unbound_anion，不强行给出伪精确 EA；异常样本按附录 A 状态机记录。
敏感性子任务：对 6–8 个柔性分子比较 single minimum → small ensemble → expanded ensemble 是否改变排序。
产出：P1 表（含 ensemble 展宽）、外部 anchor validation 小结。
核心问题：P0 → P1 是否保持排序？哪些 family 最先失效？
5.3 Stage 4：固定背景连续介质（第 5–6 周）
任务：全部 core 候选用同一生产 continuum 设定得到 P2 = ΔG_ox/red^cont；审计子集做 ε=5/10/20/40 dielectric-only 扫描（不把 SMD 非静电参数混入）。
产出：P2 表；P1→P2 的 common offset / family-dependent shift / robust rank shifts 分解。
核心问题：continuum 环境主要产生共同平移、家族依赖平移，还是真实 pairwise 重排？
5.4 Stage 5：条件 Li+ 配位态（第 7–8 周）
motif 枚举：识别 O/N/S/P donor → 单齿位点 + 几何允许的双齿对 → ESP minima 补漏 → xTB 预优化 → 按 Li–donor connectivity/距离/能量去重 → 低能 motif 送 DFT。
redox states 允许 motif 重新弛豫，不机械固定 neutral 配位方式。
state identity QC（每态必做）：fragment charge、spin density、SOMO/LUMO 定域、Li–M 键合变化、connectivity，分类为 molecule_centered_redox / Li_centered_or_mixed_redox / motif_switch / no_intact_minimum_found / dissociated_optimized_product / reaction_path_verified。
产出：ΔΔG_ox/red^coord 表；相对 ligand-exchange ΔΔG_bind(M;R)（R 为冻结参考配体，不做裸绝对 Li+ 结合能结论）；robust inversion cases 人工结构审查记录。
核心问题：Li+ 配位是否引起超出 method uncertainty 的真实 decision shift？

6.2 不确定性来源与 δ 的确定
构象 ensemble 展宽：同一分子不同低能构象的 ΔG 分布（90 分位）。
方法展宽：审计矩阵中 functional/basis/continuum 引起的 ΔG 变化。
数值下限：0.05 eV，避免 δ 被人为压小。
δ_m 按模型层（P0/P1/P2/C1）分别取值并写入预注册；分析脚本从预注册文件读取，不写死。
6.3 统计推断
所有关键指标报告 bootstrap 1000 次 BCa 95% 置信区间；LOFO 的每个 test family 样本少，必须给区间而非点估计。
报告必须同时区分 rank change 与 robust rank change beyond uncertainty；某模型 inversion 少但 unresolved 多时不得称为筛选稳定。
产出：τb/ρ 矩阵、unresolved/robust-inversion fraction 表、Top-k overlap 与 regret 曲线、family-resolved 与 cross-family 统计。

7.2 模型与数据拆分
模型复杂度顺序：linear/ridge → KRR → GPR → random forest / gradient boosting 对照；第一阶段不用深度神经网络。
三种拆分同时报告：random split（仅 interpolation baseline）、group/scaffold split、LOFO（leave-one-structural-family-out，transferability 主证据）。
统计边界：core 60–100 点，LOFO 每 family 约 10 样本，结论强度受 bootstrap 区间约束；若要把 AL/跨家族迁移作为主要结论，需扩大 broad pool 与 core labels。
7.3 Δ-learning 对比设计
Direct model：P_T = f(X(0/1))；Conditional-shift model：Δ_coord = f(X(0/1))，P(C1) = P(C0) + Δ_coord。
四项检验：Δ_coord 方差是否小于完整 target；descriptor dependence 是否更简单；LOFO 下是否仍保持优势；MAE 优势是否同步转化为 τb、Top-k overlap、regret 优势。
若 Δ 出现与 motif switching / state identity change / dissociation 共现的不连续，先做 state classification 再做 conditional regression，不继续加回归模型复杂度。
7.4 Active-learning replay（Stage 8）
设置：core set 完整 target labels 先隐藏，模拟真实 loop；每轮仅用当时可见 labels/features 做 normalization、调参与特征选择，禁止偷看完整 target set。
对照 acquisition：random、diversity（cheap descriptor 空间最远点）、uncertainty（GPR epistemic，先查 calibration）、ranking-aware（posterior 估计 p_i = P(i ∈ Top-k)，按二元 entropy 优先 query“最不确定该不该选”的候选）。
重复性：≥ 8 个初始 seeds × ≥ 10 次随机重复，报告 median 与置信区间，禁止只展示单条最漂亮 trajectory。
产出曲线：n_T → τb、O_k、R_k（n_T 为已完成昂贵 target 计算数）。这张“最小昂贵信息预算”图是项目最有方法学辨识度的产出。
八、Stage 9 与计算资源预算
8.1 Stage 9：可选显式微溶剂化验证（第 11–12 周，视资源）
对象：8–12 个候选，覆盖 ranking-stable、robust inversion、high uncertainty 与不同 family 代表。
做法：相同化学计量的局域 cluster 做 targeted check，验证 1:1 Li 配位结论的稳健性；不同配位数/阴离子数的 microstates 不做裸 Gibbs 机械平均。
本科项目时间有限时，Stage 9 不作为项目完成必要条件。

应对与结论形式
