# Stage 12（week 11）—— 介电响应是一条单参数族，判据可事前使用

Week 10 把项目的分歧量 `sigma_ij` 化简为一条无量纲判据：
`q_ij = abs(delta_i - delta_j) / abs(P1_i - P1_j) > sqrt(2)/z` 即不可分辨。
本周回答两个它留下的问题：**为什么纯介电 screening 从不改写清单**（Week 4 T3 只报了现象，没有机制），以及**这条判据能不能在花算力之前就用**。

两个部分都**不跑任何新的电子结构**：A 部分把 Week 4 的 bare-CPCM 介电扫描（`eps = 5 / 10 / 20 / 40`）提升为与电子结构台阶同形的 (台阶, 轴) 点，B 部分用穷举子采样模拟「只算 k 个分子」的决策。

## 1. 关键数字

- **介电响应是 Born 形式**：`delta(eps) = S · (1 - 1/eps)`。在 20 个 (分子, 轴) 组合上拟合的平均 R² = 0.993624，而竞争模型 Onsager 反应场 `(eps-1)/(2eps+1)` 只有 0.883528。
- **增量几何收缩**：eps 每翻一倍，位移增量减半。实测「小步/大步」比 r2 = 1.9755、r3 = 1.9867（Born 预测 2.0000 / 2.0000），而 r1 = Δ(5→10)/Δ(1→5) = 0.1324（Born 预测 0.1250，Onsager 只给 0.1786）。
- **同一条向量（分通道）**：把每一步的位移除以它自己的 `c = u(hi) - u(lo)`，得到的 `S` 在倍频台阶上一致。氧化（阳离子）通道最大相对离散 0.0096（最差 EC/ox），还原（阴离子）通道 0.1489（最差 EC/red）—— 后者松 4 倍，是 Onsager 型高阶项在阴离子上更重的直接迹象。
- **因此 `sd(delta)`、`b`、`q` 全部按 c 缩放**：介电梯度上 `b` 的符号不可能改变；`eps -> 无穷` 时 `q -> 0` 是单调的，所以「往溶剂方向走」只会让排序越来越稳，不会翻转。
- **外推可用**：只用 `eps = 5, 10, 20` 三点拟合 `S`，就能把 `eps = 40` 的位移预测到最大相对误差 2.44e-02（平均 1.43e-02 绝对值）。
- **判据可事前使用**：以「`b_hat < 0` 或 `abs(b_hat) > sqrt(2)/z`」为红牌规则，k = 8 个分子的试点即可把全部 3 个危险台阶抓住（最坏子集也不漏）。

### 2.1 Born 与 Onsager

| 模型 | 响应因子 | 平均 R² |
| --- | --- | --- |
| Born | 1 - 1/eps | 0.993624 |
| Onsager | (eps-1)/(2eps+1) | 0.883528 |

两个模型都在 eps -> 无穷 时饱和，但它们的**增量比**不同。数据站在 Born 一边：实测 r2 = 1.9755、r3 = 1.9867，Born 预测 2.0000，Onsager 只预测 1.8636 / 1.9286。

物理上这很自然：我们算的是**带电**物种（阳离子、自由基阴离子）的垂直 IP/EA，起主导的是 Born 充电项 `-(1/2)(1 - 1/eps) q²/r`，而不是中性偶极的 Onsager 反应场。

### 2.2 一条向量，五个能级

| 台阶 | c = u(hi) - u(lo) | 预测 sd(delta) |
| --- | --- | --- |
| eps 5 -> 10 | 0.1000 | —— |
| eps 10 -> 20 | 0.0500 | —— |
| eps 20 -> 40 | 0.0250 | —— |

氧化通道上 `S` 几乎不动（最大相对离散 0.0096），意味着整条梯度是**一个**向量乘上一串已知标量；于是 `sd(delta)`、`b`、`q_med` 的台阶间比值都必须等于 c 的比值，
这也正是实测 b = +0.0093 -> +0.0046 -> +0.0023 精确折半的原因。还原通道上 `S` 仍单调但略漂移（最大 0.149，最差 EC/red），对应的就是下面那条「阴离子通道外推误差更大」的注记。

## 3. B 部分：事前预警协议

危险点共 3 个：P0_to_P1/oxidation、C0_to_C1/reduction、C1_to_C2/reduction。

读法：`AUC(b_hat 均值)` 一列在 **k = 3 就已经是 1.000** —— 即使只算 3 个分子，把全部子集的 `b_hat` 平均起来也能完美分开危险与安全的台阶。但单次抽样不是平均值：`最坏 AUC` 与 `最坏灵敏度` 说明小试点会「运气差」。要保证**任何** 一个子集都不漏掉危险台阶，需要 k = 8。

工程结论：**k = 5 的试点（一半分子）平均已能抓住 96% 的危险台阶、AUC 0.946；若不允许任何一次漏判，用 k = 8。** 试点只需要 3 个分子时，单个子集的 AUC 只有 0.853，最小值低到 0.333，不可作为放行依据。

## 5. 结论

- 判据的**第四条免费通道**：Week 10 证明了层间刚性偏移（T3）与严格单调位移（Lipschitz）不收费；本周补上第三条——**自相似的平移**。只要位移向量在台阶之间只差一个已知标量，`b` 的符号就不动、`q` 只按标量缩放。
- 于是「纯介电 screening 是否产生 robust inversion」有了机制层面的答案：**不可能**，因为介电响应是 Born 形式，是一条单参数族，而清单是否被改写只取决于 `b` 的符号与 `q` 的尾部。
- 实践含义：把环境从气相一路调到导体，排序结论**单调地越来越稳**；需要担心的从来不是「加了溶剂」，而是「换了**相互之间不成比例**的两层」。
- 判据可事前使用，且成本很低：k = 8 个分子的试点足以不遗漏任何危险台阶。
