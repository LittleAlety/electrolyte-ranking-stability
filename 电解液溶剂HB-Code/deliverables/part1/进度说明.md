## 1. 口径与记号（读任何数字前先看）

- **三层臂的唯一变量规则**：`P0` = GFN2-xTB（Koopmans 代理，气相）；`P1` = ORCA r2SCAN-3c（气相，ΔSCF 三态垂直量）；`P2` = r2SCAN-3c + CPCM(SMD, 乙腈)。相邻两层之间**只有一个变量在变**：P0→P1 只换电子结构方法，P1→P2 只换环境；几何（G1）与构象在两臂间完全共享。
- **条件态**：`C0` = 自由分子；`C1` = `[LiM]⁺`（week5 运行，Stage 5）；`C2` = `[Li(M)₂]⁺` 显式第一溶剂壳（week8 运行，Stage 9）。参考配体 `R = DME`（C08，双齿 2×O 螯合、配位 motif 唯一）。
- **垂直量口径**：IP / EA 全部是垂直量，在冻结几何 G1 上取三态能量差，不做几何弛豫（几何台阶 G1→G2 单列）。
- **z 因子**：主判据是 `config/prereg.yaml` 冻结的 `z_factor.value = 1.0`；`z = 1.96`（95% 双侧带）作为保守敏感性**并列**报告。两者不得混用、不得择优引用。
- **不把 ΔSCF 负值当 EA 用**：`EA_dscf = (E_anion − E_neutral) × 27.211386`，**正值表示阴离子不束缚**；对外可比的是 `EA_conventional = −EA_dscf`。Koopmans EA（`+eps_LUMO`）与 ΔSCF EA 不是同一物理量，不可互换。
- **三层表述**：模型事实 / 统计判定 / 材料意义分列，不混写。

## 3. 核心科学结论

### 3.1 值误差 ≠ 排序误差

三臂与外部气相锚点比较：

| 臂 | MAE | tau_b |
| --- | --- | --- |
| P0 Koopmans | **1.377 eV** | 0.606 |
| GFN2-xTB ΔSCF | **4.481 eV** | 0.911 |
| P1 r2SCAN-3c | **0.251 eV** | 0.727 |

ΔSCF 的值误差是 P0 的 3.3 倍，**排序一致性却最高**；P1 的值误差最小，排序一致性反而低于 ΔSCF。**把一个臂的 MAE 当作它的决策质量是错的。**

### 3.2 位移的方差决定决策是否被改写

四级台阶同口径对照：

| 台阶 | 唯一变量 | IP 位移均值 | IP 位移 std | 氧化轴 tau_b | Top-20% 重叠 |
| --- | --- | --- | --- | --- | --- |
| P0 → P1 | 电子结构方法 | −1.550 eV | **0.714 eV** | **0.673** | 0.50 |
| P1 → P2 | 环境（气相 → SMD 乙腈） | −2.393 eV | **0.293 eV** | **0.895** | 0.75 |
| G1 → G2 | 几何（xTB 几何 vs Opt+Freq 驻点） | −0.002 eV | **0.049 eV** | **0.939** | 1.000 |
| C0 → C1 | 条件态（自由分子 → [LiM]⁺） | +4.887 eV | **0.564 eV** | **0.689** | —— |

环境台阶的平均位移比方法台阶**大 54%**，但分子间离散度只有方法台阶的 **41%**，于是排序被破坏得**更少**。**位移更大不等于决策更坏；决定决策是否被改写的是位移的方差。**

五级台阶同口径合成（Stage 10）：`rho(shift std, tau_b) = −0.851`、`rho(|mean|, tau_b) = −0.535`、`rho(std, f_unresolved) = +0.894`。最锋利的对照：P0→P1 还原轴位移最大（+7.064 eV，std 2.253）却保住排序（tau_b 0.600），C0→C1 还原轴位移相仿（−6.578 eV，std 0.832）却**换号**（tau_b −0.467）。

### 3.3 sigma 的闭式与事前判据（Stage 11）

`sigma_ij` 不是经验量，它有闭式：

- `sigma_ij = |delta_i − delta_j| / sqrt(2)`
- 逐对 RMS 恰等于逐分子位移的样本标准差
- 对层间**刚性偏移严格不变**（均匀方法偏差零成本）
- **T4**：`f_unresolved(z) = Pr(q_ij > sqrt(2)/z)`，其中 `q_ij` 是位移对目标轴的**割线斜率**；闭式与实测在 z = 1 与 z = 1.96 的 20 个点上**误差精确为 0**

可预测性：带符号斜率 `ols_slope_b` 的 AUC = **1.000**、精确置换 `p = 1/120`、LOO 10/10；无符号的 `sd(delta)` 只有 0.810 —— **符号比幅度重要**。

### 3.4 三条免费通道 + 一个闭式判据

1. **层间刚性偏移免费**（T3）：均匀平移不改排序。
2. **单调 1-Lipschitz 位移免费**：`tau_b = 1`、`f_unresolved = 0` 同时成立。
3. **自相似平移免费**（Stage 12）：若 `delta(ε) = c(ε)·delta₀`，则 `sd`/`b`/`q` 同因子缩放，`b` 符号不变、决策只会越来越稳。bare CPCM 介电扫描正落在这条通道上（Born mean R² **0.9936**；8 个介电台阶**全部** `b > 0`、`tau_b ≥ 0.867`、**无一改写清单**）——尽管 `gas → 5` 的位移均值 1.885 eV 比 P1→P2 / G1→G2 / C0→C1 / C1→C2 都大。
4. **态的刚性偏移**（Stage 13）：`SMD CDS` 项在三个电荷态上逐点相同（最大 spread 0.00000000 eV），对任何垂直 IP/EA 的贡献**精确为 0**；`Δ(D4) = Δ(gCP) = 0` 同理。

**闭式判据**：分辨率只由一条无量纲不等式决定 —— `q_ij ≤ sqrt(2)/z`。它把「这一级台阶会不会把排序糊掉」变成**开跑前的算术**。

### 3.5 还原侧定性失效

P1 下 18 个分子的气相阴离子**全部不束缚**（`unbound_anion = 18`，EA < 0）。定域在 LUMO 上的 Koopmans 图像在结构上**不可能**给出这一点，因此 P0 还原轴与真实 EA **不是同一物理量**。P0→P1 还原 tau_b（0.595）低于氧化（0.673），但还原轴 Top-10% 重叠却高达 1.000 —— 这属于**伪一致**，不可解读为代理可靠。

**T5 方法适用域**：同一泛函 r2SCAN 只换基组，加弥散（def2-TZVPD）把气相 EA 系统性下拉 **0.34–1.60 eV**，但四个分子在三臂下**都不翻转符号**。AN（0.011 eV）与 DMSO（0.014 eV）的锚点比任何 DFT 泛函的误差棒（~0.1–0.2 eV）低两个数量级 —— 本方法**不能裁断 0.01 eV 量级的阴离子束缚与否**。氧化侧（IP）不受此限制。

### 3.6 「哪些层可以不算」：最简信息预算（R12）

1. **闭式判据（花钱之前预判）**：`q_ij ≤ sqrt(2)/z`。
2. **介电层免费**：Born 单参数族，残余按 `|dE|·ε ~ 2.1 eV` 幂律衰减 → 可稀疏采样。
3. **配位饱和（次线性）**：1:1 → 1:2 → 1:3 增量同号且绝对值递减（`dd(3→2)/dd(2→1) = −0.483 / −0.098`）→ 真正要算的是第一壳。
4. **漏解层（靶向而非翻倍）**：容许量 `A_axis`（0.1523 / 0.2860 eV）把它框住；全序翻倍可换成靶向（0 漏），或只保护 Top-k 清单边界（k = 1/2 时省 91.7% / 83.3%）。

合成一句话：**先算第一壳的分子、用闭式判据筛台阶、介电层稀疏化、漏解只做靶向。**
