# 校验口径与路径引用说明（part1）

本文件用于解释 `09_校验与按周元数据/` 下三类文件的口径，以及**重组后路径引用怎么读**。

## 1. `SHA256SUMS_新结构.txt` — 本目录当前的可信校验清单

- 覆盖重组后新结构的**全部 891 个文件**（不含本清单自身与 `新结构文件清单.csv`）。
- 行格式：`<sha256>  <相对本目录的路径>`，按路径字节序排序。
- 复核方式：

  ```bash
  cd "E:/Claude Code/电解液溶剂-HB/成果输出（part1）"
  sha256sum -c --quiet "09_校验与按周元数据/SHA256SUMS_新结构.txt"    # 全部通过时无输出
  ```

- `新结构文件清单.csv` 是同一份信息的表格版：`大类,相对路径,字节数,sha256`。

## 2. `路径映射表_旧按周结构到新结构.csv` — 重组前的旧路径去哪了

- 887 行（重组前 `week1`–`week25_gate1` 下的全部文件 + 5 个顶层文件）。
- 列：`原路径(相对目录根), 原周次, 新路径(相对目录根), sha256, 是否与其他位置重复的同内容副本`。
- 用法：文档里若出现 `weekNN/outputs/weekNN/foo.json` 这类旧镜像路径，用它查出该文件在 `03_数据成果/` 等新目录下的位置。

## 3. ⚠️ 本目录的特殊之处：同名文件内容**不同**

part2 的重复副本是「逐字节相同」，去重即可。**part1 不同**：`week13` / `week14` / `week15` 有 29 组同名文件（`p2_core_set_*.csv` / `p2_summary_*.json`），但**内容互不相同**：

| 文件组 | week13 | week14 | week15 |
| --- | --- | --- | --- |
| 覆盖的介电阶梯 | ε = 5/7/10/14/20/28/40 | ε = 1000 与 `moread` 系列 | 汇总为完整阶梯 |
| 表结构 | 21 列 | 21 列 | 23 列（多 `guess` / `source`） |
| 行数 | 10 行（3 分子） | 10 行（3 分子） | **37 行（12 分子）** |

它们各自记录了**不同阶段、不同子集**的计算结果，是**真实的内容冲突而非重复**。整理时**全部原样保留**，各归各的 stage 目录。

**因此：任何「按内容去重」的做法在本目录都会丢数据。** 查重时请以「路径」而非「文件名」为键。

## 4. 文档正文里的 `outputs/...` / `scripts/...` / `config/...` 路径

**这些路径指的是代码仓库 `电解液溶剂HB-Code` 的相对路径，不是本镜像目录的路径。**

理由：全部周报、`数据结果汇总.md`、各 `verification.json` 与脚本，都是「保持仓库相对形状」的镜像产物，其正文里的相对路径同时是**复现指令**（例如「在仓库里跑 `scripts/build_deliverables.py`」）。本目录重组后已不再与仓库形状一一对应，但仓库形状没有变，所以这些引用**保持原样才是正确的**——改了它们反而会让复现指令失效。

要在这份镜像里定位具体文件，请走映射表；要在仓库里复现，请按文档原文的路径执行。
